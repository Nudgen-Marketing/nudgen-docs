## このページが役立つこと

3 つのキャンペーン タイプとそのライフサイクルを理解します。これは、適切なキャンペーン タイプを選択し、キャンペーン リストを解釈するのに役立ちます。

## 開始する前に

- Nudgen にアップロードされた連絡先
- ブランド設定（プリセット トーンまたはカスタム プロンプト）
## キャンペーン タイプ

### ワンショット キャンペーン

選択した対象ユーザーに 1 回送信される単一のメール。これは次のような場合に使用します。

- 機能またはイベントをアナウンスする
- 1 回限りのリエンゲージメント ブラストを送信する
- 長いシーケンスを作成する前にメッセージをテストする

視聴者を選択し、AI がコンテンツを生成し、プレビューして送信 (またはスケジュール) します。

### ドリップ シーケンス

メール間に遅延がある複数ステップのキャンペーン (例: 1 日目、3 日目、2 日目) 7)。これは、次の場合に使用します。

- 非アクティブなユーザーを数日間にわたってナッジする
- オープンユーザーまたはクリックしないユーザーをフォローアップする
- Duolingo スタイルの保持フローを構築する

各ステップには、独自の目標、件名、AI によって生成された本文があります。連絡先は遅延後にのみ次のステップに進みます。 **自動停止ルール** (受信者がクリックしたときやメールを開いたときに停止するなど) を設定して、関与するユーザーが後のステップの受信を停止するようにすることができます。

### ライフタイム キャンペーン

ライフタイム キャンペーンは、システムからのイベントに備えた状態を維持します。認証されたトリガーごとに最大 1 つの実行が作成され、そのトリガー内の連絡先に 1 つのナッジが送信されます。

注文確認、支払いリマインダー、イベントベースのオンボーディング、またはバックエンドが開始するその他のトランザクションおよび保持メールには、ライフタイム キャンペーンを使用します。対象ユーザーは常に **トリガー**です。保存された連絡先セグメントにすぐには送信されません。

ダッシュボードのワークフローと統合ガイダンスについては、[ライフタイム キャンペーンを使用する](/jp/campaigns/lifetime) をご覧ください。

**対象ユーザーのタイプ:** キャンペーンを作成するときに、キャンペーンを受信するユーザーを選択します: **すべての連絡先**、**タグ別** (選択したタグを持つ連絡先のみ)、または **手動** (受信者を手動で選択)。ウィザードには、開始前にリーチの推定値が表示されます。

## キャンペーンのステータス

|ステータス |意味 |
| ---------- | ----------------------------------------------------------------------- |
| **草案** |送信されませんでした。目標、対象者、コンテンツ、スケジュールを編集できます。         |
| **予定** |送信時間が設定されます。メールは予定時刻に送信されます。        |
| **アクティブ** / **送信中** |メールが送信されています。進行状況がダッシュボードに表示されます。     |
| **送信済み** |すべてのメールが送信されました。コンテンツはロックされています。分析を表示できます。  |
| **停止しました**|キャンペーンは手動で停止されました。一部の連絡先はすでに電子メールを受信している可能性があります。今後の点滴ステップはキャンセルされます。 |

<Note>
キャンペーンが送信されると、その内容を編集したり再送信したりすることはできません。別のメッセージを送信するには、新しいキャンペーンを作成します。
</Note>

### ライフタイム ライフサイクル

ライフタイム キャンペーンでは、**ドラフト** → **アクティブ** → **一時停止** → **アクティブ**、または **アクティブ/一時停止** → **アーカイブ**という別のライフサイクルが使用されます。アーカイブされたキャンペーンを再度アクティブにすることはできません。

ライフタイム キャンペーンを一時停止またはアーカイブすると、Nudgen はまだ保留中またはキューに入っている実行をキャンセルします。すでに処理中の実行でも送信することができます。実行ごとにコンテンツと送信構成のスナップショットが保存されるため、アクティブなキャンペーンへの変更は今後のトリガーにのみ適用されます。
