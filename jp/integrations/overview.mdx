## これが重要な理由

アプリを接続すると、既存の連絡先を Nudgen に取り込み、キャンペーンのオーディエンスとして選択できます。利用できる機能は、アプリやワークスペースの設定によって異なります。同期や顧客イベントを利用する前に、アプリの詳細を確認してください。

## アプリを探す

1. Nudgen アプリで **設定** → **連携**を開きます。
2. アプリ名で検索するか、**CRM**、**E コマース**、**営業・カスタマー サポート**、**マーケティング・ソーシャル メディア**で絞り込みます。
3. アプリの **接続**または**詳細を表示**を選択します。詳細ページには、現在の利用可否とプロバイダー側の要件が表示されます。

**接続済みアプリ**セクションには、既存の接続、ステータス、利用可能な場合は最終同期時刻、**管理**リンクが表示されます。**ネイティブ連携**ラベルは、Nudgen のネイティブ フローで管理される接続を示します。

## 利用可否を確認する

| 表示 | 意味 |
| --- | --- |
| **連絡先を同期できます** | この接続からの連絡先インポートがワークスペースで有効になっています。設定を続行できます。 |
| **確認中** | Nudgen がアプリの接続または連絡先同期を確認しています。現在必要な手順は詳細ページで確認してください。 |
| **接続設定が必要です** | 接続前に Nudgen 側でアプリを設定する必要があります。Nudgen サポートにお問い合わせください。 |
| **連絡先同期はまだ実装されていません** | このアプリからの連絡先インポートはまだ利用できません。 |
| **同期を利用できません** | プロバイダー側の既知の制限により、連絡先を同期できません。 |

連絡先同期を利用できない場合でも、アプリで **Composio アプリ アクセス**を利用できることがあります。その場合は、管理ページに明記されます。連携が利用可能で接続方法が設定されている場合、ディレクトリに **OAuth** や **API キー**などの接続方法が表示されることもあります。これらのバッジは選択された接続設定を示すものであり、プロバイダーのすべての機能が Nudgen で動作することを保証するものではありません。

顧客イベントへの対応状況は、連絡先同期とは別に判定されます。[ライフタイム キャンペーン イベント](/jp/integrations/lifetime-events)を参照してください。
