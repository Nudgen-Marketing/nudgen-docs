---
title: "Shopify の連絡先を接続する"
description: "Shopify を認証し、すべての顧客または特定のセグメントを選択します"
---

## これが重要な理由

Shopify の **すべての連絡先**オプションを使用すると、セグメントを作成していなくても顧客をインポートできます。特定のセグメントを選択すると、ソース オーディエンスをより限定できます。どちらの場合も、Nudgen が連絡先にメールを送信できるかどうかを判断する際には、Shopify のメール マーケティング ステータスが引き続き考慮されます。

## アプリ ディレクトリから Shopify を接続する

1. **設定** → **連携**を開き、**Shopify** を見つけます。ワークスペースに表示されている利用可否を確認してください。
2. **接続**を選択します。Shopify の設定ページには、ストア固有の非公開配布アプリについて説明されています。認証中に、Shopify の管理者が Shopify Dev Dashboard でインストールを承認します。
3. 要求された `read_customers` と `read_orders` の Admin API スコープだけを許可します。**接続**を選択し、Composio 経由で Shopify を認証します。Admin API トークンを Nudgen に貼り付ける必要はありません。
4. 認証後、**すべての連絡先**または 1 つ以上の Shopify セグメントを選択します。その後、プレビューし、許可を確認して同期を開始します。共通の手順と上限については、[接続ガイド](/jp/integrations/connect-and-sync)を参照してください。

ディレクトリからの設定は、既存の Shopify ネイティブ インストールとは別のものです。Nudgen に **以前の接続**という通知が表示された場合は、その案内に従って接続を解除してから、Composio 経由で接続してください。接続を解除しても、インポート済みの連絡先は保持されます。

## 適切な Shopify オーディエンスを選択する

| 選択肢 | インポートされる対象 |
| --- | --- |
| **すべての連絡先** | 保存済みセグメントに含まれない顧客を含む、接続された Shopify ストア全体の顧客。 |
| Shopify セグメント | 選択した保存済みセグメントに属する顧客。 |

**すべての連絡先**は他の選択肢と同時に選べません。これを選択すると、選択済みのセグメントが置き換えられ、セグメントを選択すると **すべての連絡先**が置き換えられます。同期には引き続き、ソース内の重複しない連絡先 10,000 件という上限と、ワークスペースの容量が適用されます。Shopify でセグメントを一覧表示できなくても顧客を読み取れる場合は、**すべての連絡先**を利用できることがあります。

Shopify で購読済みとマークされた顧客は、Nudgen のその他の制限に従い、メールの配信対象になる可能性があります。購読解除、未購読、保留中、無効、編集済みのマーケティング ステータスは、配信不可として扱われます。使用可能なメール送信許可のステータスがない顧客について、同意済みとはみなされません。同期前に、プレビューと許可の確認内容を確認してください。

## トラブルシューティング

<AccordionGroup>
  <Accordion title="ストアを接続できない">
    Shopify の管理者が、ストア固有のインストールと要求されたスコープを承認したことを確認します。設定ページに戻り、**接続**をもう一度試してください。ページに **接続設定が必要です**と表示される場合は、Nudgen サポートにお問い合わせください。
  </Accordion>
  <Accordion title="想定より顧客数が少ない">
    **すべての連絡先**ではなく、セグメントを選択していないか確認します。同期実行のインポート、更新、スキップの件数を確認してください。インポート可能なメールアドレスがない Shopify の顧客は、Nudgen の連絡先として作成されない場合があります。
  </Accordion>
  <Accordion title="アカウントの再接続が必要">
    **接続済みアプリ** → **管理** → **再接続**を開き、同じ Shopify ストアをもう一度認証します。
  </Accordion>
</AccordionGroup>
