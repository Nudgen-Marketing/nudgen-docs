## このページでできること

**Map Leads** を使うと、対象エリアのビジネスを検索し、利用可能な連絡先情報を確認して、選択したリードを Nudgen の連絡先に追加できます。その後、タグで連絡先を整理し、アウトリーチキャンペーンのオーディエンスとして利用できます。

## これが重要な理由

地域の見込み顧客リストを手作業で作成するには時間がかかります。Map Leads は、地図を使ったビジネス検索と連絡先情報の補完を組み合わせ、場所とビジネスカテゴリの指定から実用的な連絡先セグメントの作成までを、1 つのワークフローで行えるようにします。

Map Leads では、次のことができます。

- 都市、地域、郵便番号、または地図上の地点の周辺にあるビジネスを検索する。
- `marketing agency`、`law firm`、`design studio` などの業種で検索する。
- 住所、評価、Web サイト、電話番号、メールアドレス、ソーシャルプロフィールを、利用可能な場合に確認する。
- リードを選択する前に結果を絞り込む。
- 選択した結果を CSV にエクスポートするか、ワークスペースに直接インポートする。

<Note>
  Map Leads はベータ機能です。機能の開発に伴い、利用可否、検索範囲、結果の品質が変更される場合があります。
</Note>

## 始める前に

- Nudgen にサインインし、インポートした連絡先を追加するワークスペースを選択します。
- 対象とする場所とビジネスの種類を決めます。
- [プランの上限](/en/billing/overview)を確認し、ワークスペースに新しい連絡先を追加できる余裕があることを確認します。
- 自社と受信者に適用されるアウトリーチ、プライバシー、同意に関する規則を遵守します。

## Map Leads の仕組み

Map Leads は、指定した場所の周辺にあるビジネスを検索します。ビジネスに Web サイトがある場合、Nudgen はホーム、連絡先、会社概要などの一般公開ページを確認し、公開されているビジネス用メールアドレスやソーシャルリンクを探すことがあります。

各結果には、次の情報が含まれる場合があります。

- ビジネス名と住所
- 地図上の場所
- ビジネスカテゴリ
- 評価
- Web サイトとドメイン
- 電話番号
- 公開されているビジネス用メールアドレス
- LinkedIn、Facebook、X/Twitter、Instagram のプロフィール

すべてのビジネスがこれらの情報をすべて公開しているとは限りません。メールアドレスがない結果も確認できますが、エクスポート対象として選択したり、Nudgen の連絡先にインポートしたりすることはできません。

<Warning>
  見つかったメールアドレスが現在も有効で、確認されており、キャンペーンに適しているとは限りません。連絡する前に、選択したリードを確認し、適用される迷惑メール防止法およびプライバシー法を遵守してください。
</Warning>

## ステップ 1：Map Leads を開く

1. Nudgen ダッシュボードを開きます。
2. サイドバーから **Map Leads** を選択します。
3. インポートを始める前に、正しいワークスペースが有効になっていることを確認します。

## ステップ 2：場所を選択する

**Location** フィールドに、都市、地域、郵便番号、住所、またはその他の対応している場所を入力します。候補が表示されたら選択し、Nudgen が正しい地図エリアを使用できるようにします。

次の方法も利用できます。

- **Use my location** をクリックし、ブラウザで位置情報へのアクセスを許可する。
- 検索前に地図をクリックして、特定の地点を選択する。
- `latitude, longitude` の形式で座標を入力する。

ブラウザの位置情報へのアクセスを拒否しても、場所を入力したり、地図上の地点を選択したりできます。

## ステップ 3：ビジネスのキーワードを入力する

**Keywords** フィールドに、検索したいビジネスの種類を入力します。幅広い営業用の表現ではなく、具体的なカテゴリを使用してください。

適切な例：

- `marketing agency`
- `software company`
- `accounting firm`
- `staffing agency`
- `real estate agency`

検索フィールドの下にあるカテゴリショートカットも使用できます。Map Leads は最近の検索をブラウザに保存するため、後から同じ検索を繰り返したり削除したりできます。

## ステップ 4：検索して地図を確認する

**Search** をクリックします。結果は地図のピンとリードカードとして表示されます。

- 地図のピンをクリックすると、対応するリードカードに移動します。
- リードカードにカーソルを合わせると、対応するピンが強調表示されます。
- 次の結果ページがある場合は **Load more** をクリックします。
- Web サイトまたはソーシャルアイコンをクリックすると、新しいタブでビジネスを確認できます。

検索結果は、有用な連絡先データがあるビジネスを優先するように並べられます。ただし、検索範囲は、選択したエリアと各ビジネスが公開している情報に左右されます。

## ステップ 5：結果を絞り込む

リードリストの上にあるフィルターを使用して、現在の結果を絞り込みます。

- **Website** — Web サイトがあるビジネスを表示します。
- **Email** — メールアドレスが見つかったビジネスを表示します。
- **Phone** — 電話番号があるビジネスを表示します。
- **Rating** — 最低評価を 3、4、または 4.5 に設定します。

メールアドレスと Web サイトのフィルターはデフォルトで有効です。より幅広いビジネスを確認する場合は、これらを無効にしてください。

フィルターは、ページにすでに読み込まれている結果に適用されます。リストが短すぎる場合は、1 つ以上のフィルターを解除するか、**Load more** をクリックするか、より広い条件で検索します。

## ステップ 6：リードを選択する

保存する各リードカードのチェックボックスを選択します。リストの上にあるチェックボックスを使用すると、現在表示されている絞り込み済みのリードをすべて選択できます。

インポート対象として選択できるのは、メールアドレスがあるリードだけです。インポート前に、次の点を確認してください。

- ビジネスが対象オーディエンスに合っている。
- 場所が適切である。
- Web サイトが正しいビジネスのものである。
- メールアドレスがビジネス向けのアウトリーチに適している。
- 電話番号、評価、ソーシャルプロフィールが選定基準を満たしている。

## ステップ 7：エクスポートまたはインポートする

### 選択したリードをエクスポートする

**Export** をクリックして、選択した結果を CSV ファイルとしてダウンロードします。エクスポートには次の項目が含まれます。

- 名前
- 住所
- メールアドレス
- 電話番号
- Web サイト
- 評価
- カテゴリ
- 緯度と経度

エクスポートしても、ビジネスは Nudgen の連絡先には追加されません。

### 選択したリードをインポートする

**Import** をクリックして、選択したメールアドレス付きのリードを有効なワークスペースに追加します。

インポート中、Nudgen は次の処理を行います。

- メールアドレスがワークスペースにまだ存在しない場合、新しい連絡先を作成する。
- 同じメールアドレスがすでに存在する場合、既存の連絡先を更新する。
- メールアドレスがない選択済みの結果をスキップする。
- 他の連絡先と同じ保護方式で、インポートした連絡先情報を暗号化する。
- `map-lead` タグを追加する。
- `geo:austin-tx` などの場所タグを追加する。
- `kw:marketing-agency` などのキーワードタグを追加する。
- 住所、Web サイト、評価、検索場所、検索キーワード、利用可能なソーシャルリンクなどの参照元情報を保存する。

確認メッセージには、作成または更新された連絡先の数が表示されます。インポートした連絡先は **Contacts** に表示され、通常の連絡先と同じ検証およびマスキング処理が適用されます。

## ステップ 8：インポートしたリードをキャンペーンで使用する

1. **Contacts** を開き、インポートしたレコードを確認します。
2. `map-lead`、`geo:` タグ、または `kw:` タグで絞り込みます。
3. 対象に合わない連絡先を削除します。
4. キャンペーンを作成し、関連するタグをオーディエンスとして選択します。
5. リーチの見積もりを確認し、開始前にテスト送信します。

たとえば、Austin のマーケティング代理店を検索すると、次のタグが生成されます。

- `map-lead`
- `geo:austin-tx`
- `kw:marketing-agency`

対象を細かく絞ったキャンペーンには、場所タグとキーワードタグを組み合わせて使用します。

## ベストプラクティス

- 特定の都市または地域と、明確な 1 つのビジネスカテゴリから始めます。
- すべての結果をインポートせず、ビジネスを 1 件ずつ確認します。
- 関連性がある場合は、`hello@`、`info@`、`sales@` など、役割に基づくビジネス用アドレスを優先します。
- タグを有効に活用できるように、場所やビジネスカテゴリごとに検索を分けます。
- 見つけたオーディエンスに合わせてキャンペーンをパーソナライズします。
- 開始前にテスト送信し、送信者設定を確認します。
- 配信停止対象と購読解除の処理を有効にしておきます。

## AI アシスタントで Map Leads を使用する

対応している AI アシスタントを Nudgen MCP サーバーに接続すると、そのアシスタントから Map Leads を検索し、承認した結果を接続済みのワークスペースにインポートできます。権限、検索オプション、インポート上限については、[MCP サーバーガイド](/en/agents/mcp)を参照してください。

## 検索範囲と情報補完

ダッシュボードの新規検索は半径5 kmで開始し、選択した円の内側のビジネスのみを返します。次のページがなくなると、10、25、50 kmへの拡大を順に確認できます。追加読み込みでは場所、キーワード、半径を維持します。地図のクリックは実行中の検索を再開しません。

`enrichmentPending` は未完了のWebサイト調査を示します。利用可能な `businessSummary` と `businessSources` を確認してください。インポートした情報はキャンペーンの導入文の個別化に役立ちます。メールがない場合、調査が続いている可能性があります。
