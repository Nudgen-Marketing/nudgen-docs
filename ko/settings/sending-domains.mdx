**설정** → **사용자 지정 도메인**에서 캠페인과 테스트 이메일을 자신의 도메인 주소로 보내세요. 사용자 지정 도메인이 없으면 팀은 Nudgen 발신자를 사용합니다.

## 이것이 중요한 이유

확인된 도메인을 사용하면 수신자가 발신자 주소에서 브랜드를 알아볼 수 있습니다. Nudgen은 도메인을 사용하기 전에 필요한 DNS 레코드를 확인하고, 선택한 발신자가 나중에 사용할 수 없게 되면 전송을 일시 중지합니다.

## 이것이 중요한 이유

확인된 도메인을 사용하면 연락처가 발신자 주소에서 브랜드를 알아볼 수 있습니다. DNS 확인은 도메인을 제어하고 있으며 Nudgen이 해당 도메인에서 보낸 이메일을 인증할 수 있음을 확인합니다.

## 시작하기 전에

- 사용자 지정 발신자를 추가하고 사용하려면 팀에 **활성 유료 요금제**가 필요합니다. 무료 요금제 팀은 설정에 이미 있는 도메인을 보고 제거할 수 있습니다.
- 팀 **소유자 또는 관리자**만 도메인을 추가, 편집, 확인, 선택, 제거하고 전송을 재개할 수 있습니다. 다른 구성원은 상태와 DNS 레코드를 볼 수 있습니다.
- 도메인의 DNS 제공업체에 액세스할 수 있어야 합니다. 팀은 **하나의 사용자 지정 도메인**을 구성할 수 있습니다. 교체하려면 **Nudgen 발신자 사용**으로 전환하고 기존 도메인을 제거한 다음 새 도메인을 추가하세요.

## 도메인 추가 및 확인

1. **설정** → **사용자 지정 도메인**을 열고 `mail.example.com`처럼 소유한 도메인을 입력하세요. `@` 앞의 발신자 이메일 부분(예: `hello`)과 발신자 이름을 입력하세요. 주소는 해당 **정확한 도메인**에 있어야 합니다. `mail.example.com`에는 `hello@mail.example.com`을 사용하세요.
2. **도메인 추가**를 선택하세요. 도메인 카드에서 **DNS 레코드**를 열고 **소유권 TXT** 호스트와 값을 DNS 제공업체에 복사하세요. 호스트는 `_nudgen-verify.`로 시작합니다. 확인 후에도 이 레코드를 유지하세요.
3. **DNS 확인**을 선택하세요. 소유권이 확인되면 카드에 도메인의 **DKIM TXT** 및 **Return-Path CNAME** 레코드가 표시됩니다. 표시된 호스트와 값을 DNS 제공업체에 정확히 복사하세요. DKIM 레코드가 둘 이상 표시되면 각각 게시하세요.
4. 레코드를 저장한 후 **DNS 확인**을 다시 선택하세요. DNS 변경 사항이 전파되는 데 시간이 걸릴 수 있습니다. 소유권, DKIM, Return-Path가 확인되면 도메인은 **준비됨** 상태가 됩니다.

자신의 도메인 카드에 표시된 레코드 값을 사용하세요. 이 값은 설정마다 다릅니다. **DMARC**는 권장되지만 그 상태가 활성화를 막지는 않습니다. 상위 도메인에서 상속된 정책을 포함해 기존 DMARC 정책을 유지하세요. 이 설정을 위해 별도의 루트 SPF 레코드를 추가할 필요는 없습니다.

팀이 이전에 발신자를 선택하지 않았고 전송이 일시 중지되지 않았다면 처음 확인된 도메인이 자동으로 기본 발신자가 됩니다. 그렇지 않으면 준비된 도메인 카드에서 **기본값으로 설정**을 선택하세요. **기본 캠페인 발신자** 섹션에는 선택된 발신자가 표시됩니다. 언제든지 **Nudgen 발신자 사용**을 선택할 수 있습니다.

## 발신자 관리

- **발신자 편집**은 주소의 로컬 부분 또는 표시 이름을 변경합니다. 도메인 자체는 편집할 수 없으며, 변경하려면 도메인을 교체하세요.
- **제거**는 도메인이 기본 발신자가 아닐 때만 사용할 수 있습니다. 필요한 경우 먼저 **Nudgen 발신자 사용**을 선택하세요. 도메인을 제거하면 팀의 도메인 한 개 슬롯이 비워집니다.
- **DNS 확인**은 확인 상태를 새로 고칩니다. 카드에는 마지막 확인, 확인 오류, 소유권, DKIM, Return-Path, DMARC 상태가 표시됩니다.

## 캠페인 전송이 일시 중지된 경우

선택한 사용자 지정 도메인이 필요한 DNS 확인 또는 유료 요금제 액세스를 잃으면 캠페인 전송이 일시 중지됩니다. **대기 중인 이메일은 보존됩니다.** 페이지의 **캠페인 전송이 일시 중지됨** 아래에 이유가 표시됩니다.

1. DNS 레코드를 복구하거나 유료 액세스를 복원하세요. **Nudgen 발신자 사용**을 선택할 수도 있습니다.
2. 레코드를 복구했다면 **DNS 확인**을 선택하고 도메인이 **준비됨**인지 확인하세요.
3. **전송 재개**를 선택하세요. DNS를 수정하거나 기본 발신자를 변경하는 것만으로는 일시 중지가 해제되지 않습니다.

다른 전송 문제는 [전송 및 도달률](/ko/troubleshooting/deliverability)을 참조하세요.
