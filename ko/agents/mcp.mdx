## 개요

Nudgen은 앱 출처의 `/mcp`에서 MCP 서버를 제공합니다. Streamable HTTP를 통한 MCP `2026-07-28`을 지원하며 OAuth 2.1이 필요합니다. 브라우저에서 로그인하고 필요한 권한을 승인하세요. 기능이 활성화되면 워크스페이스 하나 또는 현재와 향후 가입하는 모든 워크스페이스의 접근을 명시적으로 허용할 수 있습니다. 대시보드 전환은 MCP 기본값을 바꾸지 않습니다.

## 여러 워크스페이스 사용하기

기존 연결은 다시 연결하여 더 넓은 접근 범위를 승인할 때까지 원래 워크스페이스로 제한됩니다. 모든 워크스페이스 접근을 허용하면 새로 가입한 곳도 자동으로 사용할 수 있습니다. 멤버 자격을 잃으면 해당 워크스페이스의 이후 작업은 차단됩니다. 역할, 구독, 할당량은 워크스페이스별로 적용됩니다.

`list_workspaces`에 `page`와 `pageSize`를 전달하면 ID, 이름, slug, 역할, 기본 상태를 확인할 수 있습니다. `teams:read`가 필요합니다. 워크스페이스 도구 호출에 `workspaceId`를 추가하면 해당 작업에만 대상을 지정합니다. 생략하면 연결 기본값을 사용합니다. 캠페인을 검토하고 보낼 때는 동일한 워크스페이스 ID를 명시하세요.

OAuth 동의 시 기본 워크스페이스를 선택하세요. **설정 → API 키 → 연결된 MCP 앱** 또는 `workspaceId`와 `teams:write` 권한을 사용하는 `set_default_workspace`로 변경할 수 있습니다. 변경 사항은 해당 연결을 사용하는 모든 채팅에 적용됩니다. 개별 호출의 대상 지정은 기본값을 바꾸지 않습니다. 기본 워크스페이스가 삭제되거나 접근할 수 없게 되면 다른 ID를 지정하거나 기본값을 수정하세요. Nudgen은 대체 대상을 임의로 선택하지 않습니다.

```jsonl
{"name":"list_workspaces","arguments":{"page":1,"pageSize":25}}
{"name":"list_campaigns","arguments":{"workspaceId":"workspace_b"}}
{"name":"set_default_workspace","arguments":{"workspaceId":"workspace_b"}}
```

기존 리소스 URI는 기본 워크스페이스를 사용합니다. 다음 템플릿은 대상을 명시적으로 지정합니다:

```text
nudgen://workspaces/{workspaceId}/brand
nudgen://workspaces/{workspaceId}/campaigns/{id}/summary
```

## 이것이 중요한 이유

어시스턴트는 연락처 확인, 업체 검색, 캠페인 초안 작성을 할 수 있습니다. 채팅에서 발송이나 예약을 허용하면 브라우저 승인 링크 없이 직접 실행합니다.

## 클라이언트 연결

프로덕션 엔드포인트는 다음과 같습니다.

```text
https://app.nudgen.net/mcp
```

OAuth를 지원하는 클라이언트에 **원격 HTTP MCP 서버**로 추가하세요. 클라이언트는 엔드포인트에서 Nudgen의 인증 서버를 검색하고 브라우저 로그인 및 동의 절차를 엽니다. 클라이언트가 액세스할 워크스페이스를 선택하고 필요한 범위만 승인하세요.

검색 문서:

| 문서 | URL |
| --- | --- |
| 보호된 리소스 메타데이터 | `https://app.nudgen.net/.well-known/oauth-protected-resource/mcp` |
| 인증 서버 | `https://app.nudgen.net/mcp-oauth` |
| 서버 카드 | `https://app.nudgen.net/.well-known/mcp/server-card.json` |

인증 서버는 PKCE S256, 리소스 바인딩, 새로 고침 토큰 순환이 포함된 인증 코드 방식을 사용합니다. Client ID Metadata Documents와 동적 클라이언트 등록을 지원합니다.

Codex CLI에서는 다음 명령을 사용하세요.

```bash
codex mcp add nudgen --url "https://app.nudgen.net/mcp" --oauth-resource "https://app.nudgen.net/mcp"
codex mcp login nudgen --scopes campaigns:read,campaigns:write,campaigns:send,teams:read,teams:write
```

`nudgen`이라는 클라이언트가 이미 구성되어 있다면 해당 항목을 `/mcp` URL로 업데이트하세요.

| 범위 | 허용되는 작업 |
| --- | --- |
| `campaigns:read` | 워크스페이스, 연락처, 캠페인, 브랜드 설정을 조회하고 지도 리드를 검색합니다. |
| `campaigns:write` | 연락처와 캠페인 초안을 만들고, 브랜드 설정을 업데이트하고, AI 초안을 생성하며, 지도 리드를 가져옵니다. |
| `campaigns:send` | 캠페인 초안 시작하기. |

조회는 `campaigns:read`, 초안과 수정은 `campaigns:write`, 허용한 이메일 작업은 `campaigns:send`를 사용하세요. 연결 시 OAuth 동의는 계속 필요합니다.

<Note>
  개인 액세스 토큰은 [개발자 API](/ko/agents/api)를 인증하지만 `/mcp` 인증에는 사용할 수 없습니다. MCP 클라이언트는 OAuth 로그인을 완료해야 합니다.
</Note>

## 사용 가능한 도구

| 작업 | 도구 | 범위 |
| --- | --- | --- |
| 워크스페이스 조회 | `get_current_user`, `list_contacts`, `list_campaigns`, `get_campaign`, `get_campaign_stats`, `get_brand_settings` | `campaigns:read` |
| 주변 비즈니스 찾기 | `search_map_leads`, `retry_map_leads_enrichment` | `campaigns:read` |
| 생성 및 편집 | `create_contact`, `create_campaign`, `update_brand_settings`, `generate_email_draft`, `import_map_leads` | `campaigns:write` |
| 캠페인 초안 시작하기 | `launch_campaign`, `send_test_email`, `activate_lifetime_campaign`, `trigger_lifetime_campaign` | `campaigns:send` |

`create_campaign`은 **캠페인 초안 (`one-time`, `drip`, `lifetime`)**을 저장합니다. 직접 발송하거나 예약할 수 없습니다. `get_campaign`을 사용하면 시작 전에 제목, 콘텐츠, 링크, 오디언스, 발신자를 확인할 수 있습니다.

서버는 `campaigns:read`에서 읽기 전용 리소스도 제공합니다.

| 리소스 | 내용 |
| --- | --- |
| `nudgen://api-catalog` | 호스팅된 도구의 이름과 설명입니다. |
| `nudgen://team/brand` | 연결된 워크스페이스의 브랜드 설정입니다. |
| `nudgen://campaigns/{id}/summary` | 한 캠페인의 전송 통계입니다. `{id}`를 캠페인 ID로 바꾸세요. |

### 지도 리드 찾기 및 가져오기

1. 어시스턴트에게 도시와 `marketing agency` 같은 비즈니스 키워드 등 위치와 비즈니스 키워드를 사용해 `search_map_leads`를 호출하도록 요청하세요.
2. 선택적 필터로는 `radiusKm`(1~100), `lat`, `lng`, 이메일을 공개한 비즈니스만 유지하는 `emailOnly`가 있습니다.
3. 결과에 `nextPageToken`이 포함되면 이를 `pageToken`으로 전달해 다음 페이지를 불러오세요.
4. 어시스턴트에게 동일한 위치와 키워드, 저장할 리드 객체를 사용해 `import_map_leads`를 호출하도록 요청하세요. 호출당 최대 200개의 리드를 받을 수 있습니다.

가져오기는 연결된 워크스페이스에 연락처를 생성합니다. 이메일이 없는 리드는 건너뜁니다. 이미 존재하는 리드는 업데이트됩니다.

### 캠페인 초안 시작하기

1. `get_campaign`으로 캠페인 이름, 제목, 내용, 실제 발신자, 예상 수신자 수와 발송 시간을 확인하세요.
2. 채팅에서 작업을 허용하세요. 어시스턴트가 캠페인 ID와 즉시 발송을 위한 `sendNow: true` 또는 시간대가 포함된 미래 시간의 `scheduledAt`을 지정하여 `launch_campaign`을 직접 호출합니다. 서로 모순되는 시간 인수를 지정하지 마세요. 이미 허용한 작업은 다시 확인할 필요가 없습니다.
3. 반환된 상태, 예약 시간, 대시보드 링크를 확인하세요. 대기열에 있거나 예약된 상태는 전달 완료가 아닙니다. 결과가 불확실하면 재시도 전에 `get_campaign`과 `get_campaign_stats`를 확인하세요.

Nudgen은 워크스페이스 권한, 발신자 준비 상태, 적격 수신자, 구독, 할당량, 캠페인 버전과 대기열을 계속 검사합니다. 생성과 수정은 초안만 저장하며 발송에는 캠페인 워커가 필요합니다.

## 액세스 관리

**설정 → API 키 → 연결된 MCP 앱**에서 접근을 확인하거나 기본값을 바꾸거나 연결을 해제하세요. 여러 워크스페이스 연결을 해제하면 모든 워크스페이스에 대한 해당 연결의 토큰과 대기 중인 인증 코드가 취소됩니다. 별도의 REST 연결에는 영향을 주지 않습니다. REST OAuth와 앱 내 어시스턴트는 기존 워크스페이스 경계를 유지합니다.

## 문제 해결

| 증상 | 해결 방법 |
| --- | --- |
| 로그인이 시작되지 않음 | 클라이언트가 OAuth를 사용하는 원격 Streamable HTTP MCP를 지원하고 `https://app.nudgen.net/mcp`를 사용하는지 확인하세요. |
| 도구에 더 많은 권한이 필요함 | 다시 연결하고 해당 워크스페이스에 필요한 범위를 승인하세요. |
| 연락처 검색에서 결과를 좁히라는 메시지가 표시됨 | 검색은 이름과 이메일 주소를 일치시키며 태그 및 상태 필터 적용 후 최대 5,000개의 연락처를 검사합니다. 필터 범위를 좁히세요. |
| 지도 리드를 가져올 때 비즈니스를 건너뜀 | 이메일이 있는 리드만 저장됩니다. `emailOnly`를 true로 설정해 다시 검색하거나 이미 이메일이 포함된 리드를 선택하세요. |
| 이전 승인 링크 또는 도구 | 도구 목록을 새로고침하고 채팅에서 직접 작업을 허용하세요. 이전 링크로는 캠페인을 시작할 수 없습니다. |
| 시작이 차단됨 | 캠페인의 초안 상태, 발신자 준비 상태, 적격 연락처, 플랜 할당량, [발송 도메인](/ko/settings/sending-domains)을 확인하세요. |

전달자 토큰과 직접 REST 엔드포인트를 사용하는 스크립트에 대해서는 [개발자 API](/ko/agents/api)를 참조하세요.

### 검색 반경 및 정보 보강

API와 MCP의 기본값은 5 km이며 정수 `radiusKm` 1~100을 지원합니다. 대시보드 확인 대화상자는 표시하지 않습니다. `nextPageToken`을 `pageToken`으로 전달할 때 같은 검색 조건을 유지하세요. 빈 페이지에도 다음 페이지가 있을 수 있습니다.

`enrichmentPending`은 완료되지 않은 웹사이트 조사를 나타냅니다. 제공되는 `businessSummary`와 `businessSources`를 검토하세요. 가져온 비즈니스 정보는 개인화된 캠페인 소개에 도움이 됩니다. 이메일이 없으면 조사가 진행 중일 수 있습니다.

`enrichmentRetryToken`이 있으면 `campaigns:read` 권한으로 `retry_map_leads_enrichment`에 `token`을 전달하세요. 토큰은 연결된 워크스페이스 전용이며 15분 후 만료되고 한 번만 사용됩니다. 가져오기 전에 `placeId`로 결과를 병합하세요. `emailOnly`는 현재 응답을 필터링하므로 재시도 후 리드가 나타날 수 있습니다.

## 초안 편집 및 지원 범위

`update_campaign`으로 기존 초안을 편집하고 `delete_campaign`으로 초안을 삭제하세요. 두 도구 모두 `campaigns:write`가 필요하며 이메일을 보내거나 예약하지 않습니다. 새로운 제품 영역에는 별도의 OAuth 권한이 필요합니다. 요청 시 다시 연결하고 해당 권한을 승인하세요.

도구 목록에서 사용 가능한 도구와 인수를 확인할 수 있습니다. 브라우저 안내 자체는 작업을 실행하지 않습니다. 결제, 공급자 인증, 초대, 워크스페이스 생성/삭제/가입, 민감한 지급 설정은 브라우저에서 완료하세요. MCP 대상이나 기본값을 변경해도 대시보드 워크스페이스는 전환되지 않습니다. 관리 기능, 인증 정보, 웹훅, 추적 콜백, 내부 도우미는 제외됩니다.

`get_api_capabilities`로 API 지원 범위를 확인하세요. 채팅에서 허용한 후 `send_test_email`, `activate_lifetime_campaign`, `trigger_lifetime_campaign`을 직접 호출하세요. 테스트는 계정 이메일로만 발송됩니다. lifetime 활성화는 향후 자동 발송을 허용합니다. 브라우저 승인이나 승인 ID는 필요하지 않습니다. 결과가 불확실하면 재시도 전에 상태나 실행 기록을 확인하세요.
