## 이 페이지의 도움

세 가지 캠페인 유형과 수명 주기를 이해하세요. 이는 올바른 캠페인 유형을 선택하고 캠페인 목록을 해석하는 데 도움이 됩니다.

## 시작하기 전에

- Nudgen에 업로드된 연락처
- 브랜드 구성(사전 설정된 톤 또는 맞춤 프롬프트)

## 캠페인 유형

### 원샷 캠페인

선택한 청중에게 한 번 전송되는 단일 이메일. 다음과 같은 경우에 이 기능을 사용하세요.

- 기능이나 이벤트 발표
- 일회성 재참여 폭발 전송
- 긴 시퀀스를 구축하기 전에 메시지 테스트

대상을 선택하면 AI가 콘텐츠를 생성하고 미리 보고 전송(또는 예약)합니다.

### 드립 시퀀스

이메일 간 지연이 포함된 다단계 캠페인(예: 1일, 3일, 1일) 7). 다음과 같은 경우에 이 기능을 사용하세요.

- 며칠에 걸쳐 비활성 사용자 유도
- 열지 않거나 클릭하지 않는 사용자에 대한 후속 조치
- 듀오링고 스타일 유지 흐름 구축

각 단계에는 고유한 목표, 주제 및 AI 생성 본문이 있습니다. 연락처는 지연 후에만 다음 단계로 이동합니다. 참여하는 사용자가 이후 단계 수신을 중단하도록 **자동 중지 규칙**(예: 수신자가 클릭하거나 이메일을 열 때 중지)을 설정할 수 있습니다.

### 평생 캠페인

평생 캠페인은 시스템의 이벤트에 대비해 유지됩니다. 인증된 각 트리거는 최대 1개의 실행을 생성하고 해당 트리거의 연락처에 하나의 넛지를 보냅니다.

백엔드에서 시작하는 주문 확인, 결제 알림, 이벤트 기반 온보딩 또는 기타 거래 및 보존 이메일에 평생 캠페인을 사용하세요. 대상은 항상 **트리거**입니다. 저장된 연락처 세그먼트로 즉시 전송되지 않습니다.

대시보드 워크플로 및 통합 지침은 [평생 캠페인 사용](/ko/campaigns/lifetime)을 참조하세요.

**대상 유형:** 캠페인을 만들 때 수신자를 선택합니다: **모든 연락처**, **태그별**(선택한 태그가 있는 연락처만) 또는 **수동**(수신자 직접 선택). 시작하기 전에 마법사에 예상 도달범위가 표시됩니다.

## 캠페인 상태

| 상태 | 의미 |
| ---------- | ---------------------------------------------------------- |
| **초안** | 전송되지 않았습니다. 목표, 대상, 콘텐츠, 일정을 편집할 수 있습니다.         |
| **예정** | 전송 시간이 설정되었습니다. 이메일은 예정된 시간에 발송됩니다.        |
| **활성** / **보내는 중** | 이메일이 전송되고 있습니다. 대시보드에 진행 상황이 표시됩니다.     |
| **보냄** | 모든 이메일이 전송되었습니다. 콘텐츠가 잠겨 있습니다. 분석을 볼 수 있습니다.  |
| **중지됨**| 캠페인이 수동으로 중지되었습니다. 일부 연락처는 이미 이메일을 받았을 수도 있습니다. 향후 드립 단계가 취소됩니다. |

<Note>
캠페인이 전송되면 내용을 편집하거나 재전송할 수 없습니다. 다른 메시지를 보내려면 새 캠페인을 만드세요.
</Note>

### 수명 주기

평생 캠페인은 **초안** → **활성** → **일시 중지됨** → **활성** 또는 **활성/일시 중지됨** → **보관됨**과 같은 별도의 수명 주기를 사용합니다. 보관된 캠페인을 다시 활성화할 수 없습니다.

평생 캠페인을 일시 중지하거나 보관하면 Nudgen은 아직 보류 중이거나 대기열에 있는 실행을 취소합니다. 이미 처리 중인 실행이 계속 전송될 수 있습니다. 각 실행이 콘텐츠의 스냅샷과 전송 구성을 저장하므로 활성 캠페인에 대한 변경 사항은 향후 트리거에만 적용됩니다.
