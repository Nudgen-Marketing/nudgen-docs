## 이것이 중요한 이유

Shopify의 **모든 연락처** 옵션을 사용하면 세그먼트를 만들지 않아도 고객을 가져올 수 있습니다. 특정 세그먼트를 선택하면 더 좁은 원본 오디언스를 사용할 수 있습니다. 두 경우 모두 Nudgen이 연락처에게 이메일을 보낼 수 있는지 판단할 때 Shopify의 이메일 마케팅 상태가 계속 적용됩니다.

## 앱 디렉터리에서 Shopify 연결

1. **설정** → **연동**을 열고 **Shopify**를 찾으세요. 워크스페이스에 표시된 사용 가능 여부를 확인하세요.
2. **연결**을 선택하세요. Shopify 설정 페이지에는 스토어별 비공개 배포 앱이 설명되어 있습니다. 승인 과정에서 Shopify 관리자가 Shopify Dev Dashboard에서 설치를 승인합니다.
3. 요청된 `read_customers` 및 `read_orders` Admin API 범위만 허용하세요. **연결**을 선택해 Composio를 통해 Shopify를 승인하세요. Admin API 토큰을 Nudgen에 붙여 넣을 필요는 없습니다.
4. 승인 후 **모든 연락처** 또는 하나 이상의 Shopify 세그먼트를 선택한 다음 미리 보고, 권한을 확인한 뒤 동기화를 시작하세요. 공통 단계와 제한은 [연결 가이드](/ko/integrations/connect-and-sync)를 참조하세요.

디렉터리 설정은 기존 네이티브 Shopify 설치와 별개입니다. Nudgen에 **이전 연결** 안내가 표시되면 해당 안내에 따라 연결을 해제한 뒤 Composio를 통해 연결하세요. 연결을 해제해도 가져온 연락처는 유지됩니다.

## 올바른 Shopify 오디언스 선택

| 선택 | 가져오는 대상 |
| --- | --- |
| **모든 연락처** | 저장된 세그먼트 밖에 있는 고객을 포함해 연결된 Shopify 스토어의 고객입니다. |
| Shopify 세그먼트 | 선택한 저장된 세그먼트에 속한 고객입니다. |

**모든 연락처**는 배타적입니다. 이 옵션을 선택하면 선택한 세그먼트가 대체되고, 세그먼트를 선택하면 **모든 연락처**가 대체됩니다. 동기화는 여전히 서로 다른 원본 연락처 10,000개 제한과 워크스페이스 용량을 따릅니다. Shopify가 세그먼트를 나열할 수 없어도 고객을 읽을 수 있다면 **모든 연락처**는 계속 사용할 수 있습니다.

구독 상태로 표시된 Shopify 고객은 Nudgen의 다른 제한을 전제로 이메일 수신 대상이 될 수 있습니다. 구독 취소, 미구독, 대기, 유효하지 않음, 삭제된 마케팅 상태는 차단된 것으로 처리됩니다. 사용 가능한 이메일 권한 상태가 없는 고객은 동의한 것으로 간주하지 않습니다. 동기화하기 전에 미리보기와 권한 확인을 검토하세요.

## 문제 해결

<AccordionGroup>
  <Accordion title="스토어를 연결할 수 없음">
    Shopify 관리자가 스토어별 설치와 요청된 범위를 승인했는지 확인하세요. 설정 페이지로 돌아가 **연결**을 다시 시도하세요. 페이지에 **연결 설정 필요**가 표시되면 Nudgen 지원팀에 문의하세요.
  </Accordion>
  <Accordion title="예상보다 고객 수가 적음">
    **모든 연락처** 대신 세그먼트를 선택했는지 확인하세요. 동기화 실행의 가져옴, 업데이트됨, 건너뜀 수를 확인하세요. 가져올 수 있는 이메일 주소가 없는 Shopify 고객은 Nudgen 연락처가 되지 않을 수 있습니다.
  </Accordion>
  <Accordion title="계정을 다시 연결해야 함">
    **연결된 앱** → **관리** → **다시 연결**을 연 다음 같은 Shopify 스토어를 다시 승인하세요.
  </Accordion>
</AccordionGroup>
