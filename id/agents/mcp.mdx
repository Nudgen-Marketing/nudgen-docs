## Ikhtisar

Nudgen menyediakan server MCP di endpoint `/mcp` pada origin aplikasi Anda. Server ini menggunakan MCP `2026-07-28` melalui Streamable HTTP dan memerlukan OAuth 2.1. Hubungkan klien yang mendukung transport tersebut. Masuk ke Nudgen di browser, pilih ruang kerja, lalu setujui izin yang diminta klien. Koneksi Anda tetap terikat ke ruang kerja tersebut, meskipun nanti Anda beralih ruang kerja di dasbor.

## Mengapa hal ini penting

Asisten dapat memeriksa kontak, mencari bisnis, dan membuat draf kampanye. Izinkan pengiriman atau penjadwalan di chat. Asisten langsung menjalankan tindakan tanpa tautan persetujuan browser.

## Hubungkan klien Anda

Endpoint produksi adalah:

```text
https://app.nudgen.net/mcp
```

Tambahkan endpoint tersebut sebagai **server MCP HTTP jarak jauh** di klien yang mendukung OAuth. Klien akan menemukan server otorisasi Nudgen dari endpoint tersebut, lalu membuka alur masuk dan persetujuan di browser. Pilih ruang kerja yang ingin diakses klien dan setujui hanya cakupan yang diperlukan.

Dokumen discovery:

| Dokumen | URL |
| --- | --- |
| Metadata sumber daya terlindungi | `https://app.nudgen.net/.well-known/oauth-protected-resource/mcp` |
| Server otorisasi | `https://app.nudgen.net/mcp-oauth` |
| Kartu server | `https://app.nudgen.net/.well-known/mcp/server-card.json` |

Server otorisasi menggunakan authorization code dengan PKCE S256, resource binding, dan rotasi refresh token. Server ini menerima Client ID Metadata Documents dan pendaftaran klien dinamis.

Untuk Codex CLI, gunakan:

```bash
codex mcp add nudgen --url "https://app.nudgen.net/mcp" --oauth-resource "https://app.nudgen.net/mcp"
codex mcp login nudgen --scopes campaigns:read,campaigns:write,campaigns:send
```

Jika klien bernama `nudgen` sudah dikonfigurasi, perbarui entri tersebut dengan URL `/mcp`.

| Cakupan | Izin yang diberikan |
| --- | --- |
| `campaigns:read` | Memeriksa ruang kerja, kontak, kampanye, pengaturan merek, dan mencari prospek di peta. |
| `campaigns:write` | Membuat kontak dan draf kampanye, memperbarui pengaturan merek, menghasilkan draf AI, dan mengimpor prospek dari peta. |
| `campaigns:send` | Luncurkan draf kampanye. |

Gunakan `campaigns:read` untuk membaca, `campaigns:write` untuk draf dan perubahan, serta `campaigns:send` untuk tindakan email yang Anda izinkan. Persetujuan OAuth tetap diperlukan.

<Note>
  Personal Access Token mengautentikasi [API Pengembang](/id/agents/api), tetapi tidak mengautentikasi `/mcp`. Klien MCP harus menyelesaikan proses masuk OAuth.
</Note>

## Alat yang tersedia

| Tugas | Alat | Cakupan |
| --- | --- | --- |
| Memeriksa ruang kerja Anda | `get_current_user`, `list_contacts`, `list_campaigns`, `get_campaign`, `get_campaign_stats`, `get_brand_settings` | `campaigns:read` |
| Menemukan bisnis di sekitar | `search_map_leads`, `retry_map_leads_enrichment` | `campaigns:read` |
| Membuat dan mengedit | `create_contact`, `create_campaign`, `update_brand_settings`, `generate_email_draft`, `import_map_leads` | `campaigns:write` |
| Luncurkan draf kampanye | `launch_campaign`, `send_test_email`, `activate_lifetime_campaign`, `trigger_lifetime_campaign` | `campaigns:send` |

`create_campaign` menyimpan **draf kampanye (`one-time`, `drip`, atau `lifetime`)**. Alat ini tidak dapat langsung mengirim atau menjadwalkan kampanye. `get_campaign` memungkinkan Anda memeriksa subjek, konten, tautan, audiens, dan pengirim sebelum peluncuran.

Server juga menyediakan sumber daya hanya-baca melalui `campaigns:read`:

| Sumber daya | Isi |
| --- | --- |
| `nudgen://api-catalog` | Nama dan deskripsi alat yang tersedia di server. |
| `nudgen://team/brand` | Pengaturan merek untuk ruang kerja yang terhubung. |
| `nudgen://campaigns/{id}/summary` | Statistik pengiriman untuk satu kampanye. Ganti `{id}` dengan ID kampanye. |

### Temukan dan impor prospek dari peta

1. Minta asisten memanggil `search_map_leads` dengan lokasi dan kata kunci bisnis, seperti kota dan `marketing agency`.
2. Filter opsionalnya adalah `radiusKm` (1–100), `lat` dan `lng`, serta `emailOnly` untuk mempertahankan bisnis yang mencantumkan email.
3. Jika hasil menyertakan `nextPageToken`, teruskan nilainya sebagai `pageToken` untuk memuat halaman berikutnya.
4. Minta asisten memanggil `import_map_leads` dengan lokasi dan kata kunci yang sama, beserta objek prospek yang akan disimpan. Setiap panggilan menerima hingga 200 prospek.

Proses impor menulis kontak ke ruang kerja yang terhubung. Prospek tanpa email akan dilewati. Prospek yang sudah ada akan diperbarui.

### Luncurkan draf kampanye

1. Tinjau nama kampanye, subjek, isi, pengirim efektif, perkiraan penerima, dan waktu melalui `get_campaign`.
2. Izinkan tindakan di chat. Asisten langsung memanggil `launch_campaign` dengan ID kampanye dan `sendNow: true` untuk mengirim sekarang atau `scheduledAt` dengan waktu mendatang beserta zona waktu. Jangan gabungkan waktu yang bertentangan. Izin yang sudah diberikan tidak perlu dikonfirmasi lagi.
3. Periksa status, waktu terjadwal, dan tautan dashboard yang dikembalikan. Masuk antrean atau terjadwal belum berarti terkirim. Periksa `get_campaign` dan `get_campaign_stats` sebelum mengulang hasil yang belum pasti.

Nudgen tetap memeriksa izin workspace, kesiapan pengirim, penerima yang memenuhi syarat, langganan, kuota, versi kampanye, dan antrean. Pembuatan serta pengeditan hanya menyimpan draf; pengiriman memerlukan worker kampanye.

## Kelola akses

Buka **Pengaturan** → **Kunci API** → **Aplikasi MCP terhubung** untuk memeriksa atau mencabut akses. Pencabutan menonaktifkan token. Kehilangan keanggotaan workspace juga memblokir akses. Hubungkan kembali melalui OAuth bila diperlukan.

## Pemecahan masalah

| Gejala | Yang harus dilakukan |
| --- | --- |
| Proses masuk tidak dimulai | Pastikan klien mendukung MCP Streamable HTTP jarak jauh dengan OAuth dan menggunakan `https://app.nudgen.net/mcp`. |
| Alat memerlukan izin tambahan | Hubungkan kembali dan setujui cakupan yang diperlukan untuk ruang kerja tersebut. |
| Pencarian kontak meminta Anda mempersempit hasil | Pencarian mencocokkan nama dan alamat email, serta memindai paling banyak 5.000 kontak setelah filter tag dan status diterapkan. Persempit filternya. |
| Impor prospek dari peta melewati sebuah bisnis | Hanya prospek dengan email yang disimpan. Cari kembali dengan `emailOnly` bernilai true, atau pilih prospek yang sudah menyertakan email. |
| Tautan atau alat persetujuan lama | Perbarui daftar alat dan izinkan tindakan langsung di chat; tautan lama tidak dapat meluncurkan kampanye. |
| Peluncuran diblokir | Periksa status draf kampanye, kesiapan pengirim, kontak yang memenuhi syarat, kuota paket, dan [domain pengiriman](/id/settings/sending-domains). |

Untuk skrip yang menggunakan bearer token dan endpoint REST langsung, lihat [API Pengembang](/id/agents/api).

### Radius pencarian dan pengayaan

API dan MCP memakai 5 km secara default dan menerima bilangan bulat `radiusKm` 1–100 tanpa dialog konfirmasi dasbor. Pertahankan parameter saat mengirim `nextPageToken` sebagai `pageToken`. Halaman kosong masih dapat memiliki halaman berikutnya.

`enrichmentPending` menandai riset situs yang belum selesai. Tinjau `businessSummary` dan `businessSources` jika tersedia. Konteks bisnis yang diimpor dapat membantu pembuka kampanye yang dipersonalisasi. Email yang belum ada mungkin masih diteliti.

Jika ada `enrichmentRetryToken`, panggil `retry_map_leads_enrichment` dengan `token` dan `campaigns:read`. Token terikat ke ruang kerja tersambung, berlaku 15 menit, dan hanya sekali pakai. Gabungkan hasil berdasarkan `placeId` sebelum impor. `emailOnly` menyaring respons saat ini; lead dapat muncul setelah percobaan ulang.

## Mengedit draf dan cakupan produk

Gunakan `update_campaign` untuk mengedit draf yang ada dan `delete_campaign` untuk menghapus draf. Keduanya memerlukan `campaigns:write`; keduanya tidak mengirim atau menjadwalkan email. Area produk baru memerlukan izin OAuth tersendiri. Hubungkan kembali dan setujui izin tersebut saat diminta.

Daftar alat menampilkan alat yang tersedia beserta argumennya. Pengalihan ke browser tidak menjalankan tindakan: selesaikan pembayaran, otorisasi penyedia, pengiriman undangan, perpindahan ruang kerja, dan pengaturan pencairan sensitif di browser. Koneksi MCP tetap terikat pada ruang kerja yang diotorisasi. Administrasi, kredensial, webhook, callback pelacakan, dan asisten internal tidak disertakan.

Gunakan `get_api_capabilities` untuk memeriksa cakupan API. Setelah izin di chat, panggil langsung `send_test_email`, `activate_lifetime_campaign`, atau `trigger_lifetime_campaign`. Pengujian hanya dikirim ke email akun. Aktivasi lifetime mengizinkan pengiriman otomatis berikutnya. Tidak diperlukan persetujuan browser atau ID persetujuan. Periksa status atau riwayat eksekusi sebelum mengulang hasil yang belum pasti.
