## Was diese Seite Ihnen bietet

Mit **Map Leads** finden Sie Unternehmen in einem Zielgebiet, prüfen verfügbare Geschäftskontaktdaten und fügen ausgewählte Leads zu Ihren Nudgen-Kontakten hinzu. Anschließend können Sie diese Kontakte mit Tags organisieren und als Zielgruppe für eine Outreach-Kampagne verwenden.

## Warum das wichtig ist

Der manuelle Aufbau einer lokalen Interessentenliste ist zeitaufwendig. Map Leads verbindet die kartenbasierte Unternehmenssuche mit Kontaktanreicherung, sodass Sie in einem einzigen Workflow von einem Standort und einer Unternehmenskategorie zu einem nutzbaren Kontaktsegment gelangen.

Map Leads hilft Ihnen dabei:

- Unternehmen in der Nähe einer Stadt, eines Stadtteils, einer Postleitzahl oder eines Kartenpunkts zu finden.
- Nach einem Unternehmenstyp wie `marketing agency`, `law firm` oder `design studio` zu suchen.
- Adressen, Bewertungen, Websites, Telefonnummern, E-Mail-Adressen und Social-Media-Profile zu prüfen, sofern verfügbar.
- Ergebnisse vor der Auswahl von Leads zu filtern.
- Ausgewählte Ergebnisse als CSV zu exportieren oder direkt in Ihren Workspace zu importieren.

<Note>
  Map Leads ist eine Beta-Funktion. Verfügbarkeit, Suchabdeckung und Ergebnisqualität können sich während der Weiterentwicklung der Funktion ändern.
</Note>

## Bevor Sie beginnen

- Melden Sie sich bei Nudgen an und wählen Sie den Workspace aus, der die importierten Kontakte erhalten soll.
- Legen Sie fest, welchen Standort und welche Art von Unternehmen Sie ansprechen möchten.
- Stellen Sie sicher, dass Ihr Workspace innerhalb seiner [Plan-Limits](/en/billing/overview) Platz für neue Kontakte hat.
- Beachten Sie die für Ihr Unternehmen und Ihre Empfänger geltenden Regeln für Outreach, Datenschutz und Einwilligung.

## So funktioniert Map Leads

Map Leads sucht rund um den von Ihnen angegebenen Standort nach Unternehmen. Wenn ein Unternehmen eine Website hat, kann Nudgen öffentlich zugängliche Seiten wie die Startseite, Kontaktseite und Über-uns-Seite auf eine veröffentlichte geschäftliche E-Mail-Adresse und Social-Media-Links prüfen.

Jedes Ergebnis kann Folgendes enthalten:

- Unternehmensname und Adresse
- Kartenposition
- Unternehmenskategorien
- Bewertung
- Website und Domain
- Telefonnummer
- Veröffentlichte geschäftliche E-Mail-Adresse
- LinkedIn-, Facebook-, X/Twitter- oder Instagram-Profil

Nicht jedes Unternehmen veröffentlicht alle diese Angaben. Ein Ergebnis ohne E-Mail-Adresse kann weiterhin geprüft, aber nicht für den Export ausgewählt oder in Nudgen-Kontakte importiert werden.

<Warning>
  Eine gefundene E-Mail-Adresse ist keine Garantie dafür, dass die Adresse aktuell, betreut oder für Ihre Kampagne geeignet ist. Prüfen Sie Ihre ausgewählten Leads und halten Sie die geltenden Anti-Spam- und Datenschutzgesetze ein, bevor Sie Kontakt aufnehmen.
</Warning>

## Schritt 1: Map Leads öffnen

1. Öffnen Sie Ihr Nudgen-Dashboard.
2. Wählen Sie in der Seitenleiste **Map Leads** aus.
3. Vergewissern Sie sich vor jedem Import, dass der richtige Workspace aktiv ist.

## Schritt 2: Standort auswählen

Geben Sie im Feld **Standort** eine Stadt, einen Stadtteil, eine Postleitzahl, eine Adresse oder einen anderen unterstützten Ort ein. Wählen Sie einen Vorschlag aus, sobald er erscheint, damit Nudgen den richtigen Kartenbereich verwenden kann.

Sie können außerdem:

- Auf **Meinen Standort verwenden** klicken und den Standortzugriff in Ihrem Browser erlauben.
- Vor der Suche auf die Karte klicken, um einen bestimmten Punkt auszuwählen.
- Koordinaten als `latitude, longitude` eingeben.

Wenn Sie die Standortberechtigung im Browser verweigern, können Sie dennoch einen Standort eingeben oder einen Punkt auf der Karte auswählen.

## Schritt 3: Unternehmens-Keyword eingeben

Beschreiben Sie im Feld **Keywords** die Art von Unternehmen, die Sie finden möchten. Verwenden Sie eine konkrete Kategorie anstelle einer allgemeinen Verkaufsphrase.

Gute Beispiele:

- `marketing agency`
- `software company`
- `accounting firm`
- `staffing agency`
- `real estate agency`

Sie können auch eine der Kategorie-Schnelloptionen unter den Suchfeldern verwenden. Map Leads speichert kürzlich durchgeführte Suchen in Ihrem Browser, damit Sie diese später wiederholen oder entfernen können.

## Schritt 4: Suchen und Karte prüfen

Klicken Sie auf **Suchen**. Die Ergebnisse erscheinen als Kartenmarkierungen und Lead-Karten.

- Klicken Sie auf eine Kartenmarkierung, um zur zugehörigen Lead-Karte zu springen.
- Bewegen Sie den Mauszeiger über eine Lead-Karte, um die zugehörige Markierung hervorzuheben.
- Klicken Sie auf **Mehr laden**, wenn eine weitere Ergebnisseite verfügbar ist.
- Klicken Sie auf eine Website oder ein Social-Media-Symbol, um das Unternehmen in einem neuen Tab zu prüfen.

Die Suchergebnisse sind so sortiert, dass Unternehmen mit nützlichen Kontaktdaten priorisiert werden. Die Abdeckung hängt dennoch vom ausgewählten Gebiet und den Informationen ab, die jedes Unternehmen veröffentlicht.

## Schritt 5: Ergebnisse filtern

Verwenden Sie die Filter über der Lead-Liste, um die aktuellen Ergebnisse einzugrenzen:

- **Website** — Unternehmen mit einer Website anzeigen.
- **E-Mail** — Unternehmen mit einer gefundenen E-Mail-Adresse anzeigen.
- **Telefon** — Unternehmen mit einer Telefonnummer anzeigen.
- **Bewertung** — Eine Mindestbewertung von 3, 4 oder 4,5 festlegen.

Die Filter für E-Mail und Website sind standardmäßig aktiviert. Deaktivieren Sie sie, wenn Sie eine größere Auswahl an Unternehmen prüfen möchten.

Die Filter gelten für die bereits auf der Seite geladenen Ergebnisse. Ist die Liste zu kurz, entfernen Sie einen oder mehrere Filter, klicken Sie auf **Mehr laden** oder führen Sie eine breiter gefasste Suche durch.

## Schritt 6: Leads auswählen

Aktivieren Sie das Kontrollkästchen auf jeder Lead-Karte, die Sie behalten möchten. Mit dem Kontrollkästchen über der Liste können Sie außerdem alle derzeit sichtbaren, gefilterten Leads auswählen.

Nur Leads mit einer E-Mail-Adresse können für den Import ausgewählt werden. Prüfen Sie vor dem Import:

- Das Unternehmen entspricht Ihrer gewünschten Zielgruppe.
- Der Standort ist relevant.
- Die Website gehört zum richtigen Unternehmen.
- Die E-Mail-Adresse scheint für geschäftliche Kontaktaufnahme geeignet zu sein.
- Telefonnummer, Bewertung und Social-Media-Profile erfüllen Ihre Qualifikationskriterien.

## Schritt 7: Exportieren oder importieren

### Ausgewählte Leads exportieren

Klicken Sie auf **Exportieren**, um die ausgewählten Ergebnisse als CSV-Datei herunterzuladen. Der Export enthält:

- Name
- Adresse
- E-Mail
- Telefon
- Website
- Bewertung
- Kategorien
- Breiten- und Längengrad

Durch den Export werden die Unternehmen nicht zu Ihren Nudgen-Kontakten hinzugefügt.

### Ausgewählte Leads importieren

Klicken Sie auf **Importieren**, um ausgewählte Leads mit E-Mail-Adresse zum aktiven Workspace hinzuzufügen.

Beim Import führt Nudgen folgende Schritte aus:

- Erstellt einen neuen Kontakt, wenn die E-Mail-Adresse noch nicht im Workspace vorhanden ist.
- Aktualisiert den bestehenden Kontakt, wenn dieselbe E-Mail-Adresse bereits vorhanden ist.
- Überspringt jedes ausgewählte Ergebnis ohne E-Mail-Adresse.
- Verschlüsselt importierte Kontaktdaten mit denselben Schutzmechanismen wie andere Kontakte.
- Fügt den Tag `map-lead` hinzu.
- Fügt einen Standort-Tag wie `geo:austin-tx` hinzu.
- Fügt einen Keyword-Tag wie `kw:marketing-agency` hinzu.
- Speichert Quelldetails, darunter Adresse, Website, Bewertung, Suchstandort, Such-Keywords und verfügbare Social-Media-Links.

Die Bestätigungsmeldung zeigt an, wie viele Kontakte erstellt oder aktualisiert wurden. Importierte Kontakte erscheinen unter **Kontakte** und unterliegen der üblichen Kontaktvalidierung und Maskierung.

## Schritt 8: Importierte Leads in einer Kampagne verwenden

1. Öffnen Sie **Kontakte** und prüfen Sie die importierten Einträge.
2. Filtern Sie nach `map-lead`, dem Tag `geo:` oder dem Tag `kw:`.
3. Entfernen Sie Kontakte, die nicht gut passen.
4. Erstellen Sie eine Kampagne und wählen Sie die relevanten Tags als Zielgruppe aus.
5. Prüfen Sie die Reichweitenschätzung und führen Sie vor dem Start einen Testversand durch.

Eine Suche nach Marketingagenturen in Austin kann beispielsweise folgende Tags erzeugen:

- `map-lead`
- `geo:austin-tx`
- `kw:marketing-agency`

Verwenden Sie Standort- und Keyword-Tags gemeinsam, wenn Sie eine eng abgegrenzte Kampagne erstellen möchten.

## Best Practices

- Beginnen Sie mit einer konkreten Stadt oder einem Stadtteil und einer klaren Unternehmenskategorie.
- Prüfen Sie Unternehmen einzeln, anstatt jedes Ergebnis zu importieren.
- Bevorzugen Sie rollenbasierte geschäftliche Adressen wie `hello@`, `info@` oder `sales@`, wenn diese relevant sind.
- Führen Sie separate Suchen für verschiedene Standorte oder Unternehmenskategorien durch, damit die zugehörigen Tags nützlich bleiben.
- Personalisieren Sie die Kampagne für die gefundene Zielgruppe.
- Führen Sie einen Testversand durch und prüfen Sie Ihre Absendereinrichtung vor dem Start.
- Lassen Sie die Behandlung von Unterdrückungen und Abmeldungen aktiviert.

## Fehlerbehebung

<AccordionGroup>
  <Accordion title="Es werden keine Unternehmen angezeigt">
    Prüfen Sie, ob sowohl das Standort- als auch das Keyword-Feld ausgefüllt sind. Wählen Sie einen vorgeschlagenen Standort aus, versuchen Sie es mit einer breiteren Unternehmenskategorie oder wählen Sie einen nahe gelegenen Punkt auf der Karte.
  </Accordion>
  <Accordion title="Die Liste ist nach einer Suche leer">
    Die aktiven Filter blenden möglicherweise Ergebnisse aus. Entfernen Sie die Filter für E-Mail, Website, Telefon oder Bewertung. Sie können auch auf **Mehr laden** klicken, wenn eine weitere Ergebnisseite verfügbar ist.
  </Accordion>
  <Accordion title="Ein Unternehmen hat keine E-Mail-Adresse">
    Das Unternehmen veröffentlicht möglicherweise auf den für Nudgen zugänglichen Seiten keine E-Mail-Adresse. Sie können die Website und andere verfügbare Angaben prüfen, das Ergebnis jedoch nicht für den Export auswählen oder in Kontakte importieren.
  </Accordion>
  <Accordion title="„Meinen Standort verwenden“ funktioniert nicht">
    Erlauben Sie der Nudgen-App in Ihrem Browser oder Betriebssystem den Standortzugriff. Wenn Sie Ihren Standort nicht teilen möchten, geben Sie einen Ort ein oder klicken Sie auf einen Punkt auf der Karte.
  </Accordion>
  <Accordion title="Beim Import wurden weniger Kontakte erstellt als ausgewählt">
    Ergebnisse ohne E-Mail-Adresse werden übersprungen. Eine übereinstimmende E-Mail-Adresse, die bereits im Workspace vorhanden ist, wird aktualisiert und nicht als neuer Kontakt gezählt. Prüfen Sie in der Importzusammenfassung die Gesamtzahlen für erstellte, aktualisierte und übersprungene Kontakte.
  </Accordion>
  <Accordion title="Derselbe Kontakt ist bereits vorhanden">
    Nudgen gleicht Kontakte innerhalb des aktiven Workspace anhand der E-Mail-Adresse ab. Beim erneuten Import des Leads wird der bestehende Kontakt aktualisiert, statt ein Duplikat zu erstellen.
  </Accordion>
</AccordionGroup>

## Map Leads mit einem KI-Assistenten verwenden

Wenn Sie einen unterstützten KI-Assistenten mit dem Nudgen MCP-Server verbinden, kann er Map Leads durchsuchen und genehmigte Ergebnisse in den verbundenen Workspace importieren. Informationen zu Berechtigungen, Suchoptionen und Importlimits finden Sie im [MCP-Server-Leitfaden](/en/agents/mcp).
