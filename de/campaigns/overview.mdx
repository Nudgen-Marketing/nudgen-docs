## Was diese Seite Ihnen hilft

Verstehen Sie die drei Kampagnentypen und ihre Lebenszyklen. Dies hilft Ihnen, den richtigen Kampagnentyp auszuwählen und Ihre Kampagnenliste zu interpretieren.

## Bevor Sie beginnen

- In Nudgen hochgeladene Kontakte
- Eine Markenkonfiguration (voreingestellter Ton oder benutzerdefinierte Aufforderung)

## Kampagnentypen

### One-Shot-Kampagnen

Eine einzelne E-Mail, die einmal an Ihre ausgewählte Zielgruppe gesendet wird. Verwenden Sie dies, wenn Sie:

- eine Funktion oder Veranstaltung ankündigen möchten
- einen einmaligen Re-Engagement-Blast senden
- eine Nachricht testen, bevor Sie eine längere Sequenz erstellen

Sie wählen die Zielgruppe aus, die KI generiert den Inhalt, Sie zeigen eine Vorschau an und senden ihn (oder planen).

### Drip-Sequenzen

Eine mehrstufige Kampagne mit Verzögerungen zwischen E-Mails (z. B. Tag 1, Tag 3, Tag 7). Verwenden Sie dies, wenn Sie Folgendes erreichen möchten:

- Inaktive Benutzer über mehrere Tage hinweg fördern
- Nicht-Öffner oder Nicht-Klicker weiterverfolgen
- Einen Aufbewahrungsfluss im Duolingo-Stil erstellen

Jeder Schritt hat sein eigenes Ziel, Thema und einen KI-generierten Text. Kontakte wechseln erst nach der Verzögerung zum nächsten Schritt. Sie können **Auto-Stop-Regeln** festlegen (z. B. stoppen, wenn ein Empfänger klickt oder die E-Mail öffnet), sodass Benutzer, die sich engagieren, keine weiteren Schritte mehr erhalten.

### Lifetime-Kampagnen

Eine Lifetime-Kampagne bleibt für Ereignisse aus Ihrem System bereit. Jeder authentifizierte Auslöser erstellt höchstens eine Ausführung und sendet einen Anstoß an den Kontakt in diesem Auslöser.

Verwenden Sie eine Lifetime-Kampagne für Bestellbestätigungen, Zahlungserinnerungen, ereignisbasiertes Onboarding oder andere Transaktions- und Aufbewahrungs-E-Mails, die Ihr Backend initiiert. Seine Zielgruppe ist immer **Trigger** – es wird nicht sofort an ein gespeichertes Kontaktsegment gesendet.

Den Dashboard-Workflow und die Integrationsanleitung finden Sie unter [Lifetime-Kampagnen verwenden] (/de/campaigns/lifetime).

**Zielgruppentypen:** Beim Erstellen einer Kampagne wählen Sie aus, wer sie erhält: **Alle Kontakte**, **Nach Tags** (nur Kontakte mit ausgewählten Tags) oder **Manuell** (Empfänger manuell auswählen). Der Assistent zeigt vor dem Start eine Reichweitenschätzung an.

## Kampagnenstatus

| Status | Bedeutung |
| ---------- | ----------------------------------------------------------------------- |
| **Entwurf** | Nicht gesendet. Sie können Ziele, Zielgruppe, Inhalte und Zeitplan bearbeiten.         |
| **Geplant** | Der Sendezeitpunkt ist eingestellt. E-Mails werden zur geplanten Zeit verschickt.        |
| **Aktiv** / **Senden** | E-Mails werden versendet. Der Fortschritt wird im Dashboard angezeigt.     |
| **Gesendet** | Alle E-Mails wurden gesendet. Der Inhalt ist gesperrt; Sie können Analysen anzeigen.  |
| **Gestoppt**| Die Kampagne wurde manuell gestoppt. Einige Kontakte haben möglicherweise bereits E-Mails erhalten. Zukünftige Tropfschritte werden abgebrochen. |

<Note>
Sobald eine Kampagne gesendet wurde, können Sie ihren Inhalt nicht mehr bearbeiten oder erneut senden. Erstellen Sie eine neue Kampagne, um eine andere Nachricht zu senden.
</Note>

### Lebenslanger Lebenszyklus

Lebenslange Kampagnen verwenden einen separaten Lebenszyklus: **Entwurf** → **Aktiv** → **Pausiert** → **Aktiv** oder **Aktiv/Pausiert** → **Archiviert**. Sie können eine archivierte Kampagne nicht reaktivieren.

Wenn Sie eine Lifetime-Kampagne pausieren oder archivieren, bricht Nudgen Ausführungen ab, die noch ausstehen oder in der Warteschlange stehen. Eine bereits verarbeitete Ausführung sendet möglicherweise noch. Änderungen an einer aktiven Kampagne gelten nur für zukünftige Auslöser, da bei jeder Ausführung ein Snapshot des Inhalts und der Sendekonfiguration gespeichert wird.
