## Обзор

Nudgen размещает сервер MCP по конечной точке `/mcp` на домене вашего приложения. Он поддерживает MCP `2026-07-28` через Streamable HTTP и требует OAuth 2.1. Подключите клиент, который поддерживает этот транспорт. Войдите в Nudgen в браузере, выберите рабочее пространство и подтвердите разрешения, запрашиваемые клиентом. Подключение останется привязанным к этому рабочему пространству, даже если позже вы переключитесь на другое в дашборде.

## Почему это важно

Ассистент может просматривать контакты, искать компании и создавать черновики кампаний. Разрешите отправку или планирование в чате: ассистент выполнит действие напрямую, без ссылки подтверждения в браузере.

## Подключение клиента

Рабочая конечная точка:

```text
https://app.nudgen.net/mcp
```

Добавьте ее в клиент с поддержкой OAuth как **удаленный HTTP-сервер MCP**. Клиент обнаружит сервер авторизации Nudgen через эту конечную точку и откроет в браузере процесс входа и предоставления согласия. Выберите рабочее пространство, к которому клиент должен получить доступ, и подтвердите только необходимые области доступа.

Документы обнаружения:

| Документ | URL |
| --- | --- |
| Метаданные защищенного ресурса | `https://app.nudgen.net/.well-known/oauth-protected-resource/mcp` |
| Сервер авторизации | `https://app.nudgen.net/mcp-oauth` |
| Карточка сервера | `https://app.nudgen.net/.well-known/mcp/server-card.json` |

Сервер авторизации использует код авторизации с PKCE S256, привязку к ресурсу и ротацию токенов обновления. Он поддерживает документы метаданных Client ID и динамическую регистрацию клиентов.

Для Codex CLI используйте:

```bash
codex mcp add nudgen --url "https://app.nudgen.net/mcp" --oauth-resource "https://app.nudgen.net/mcp"
codex mcp login nudgen --scopes campaigns:read,campaigns:write,campaigns:send
```

Если клиент с именем `nudgen` уже настроен, обновите его запись, указав URL `/mcp`.

| Область доступа | Что она разрешает |
| --- | --- |
| `campaigns:read` | Просматривать рабочее пространство, контакты, кампании и настройки бренда, а также искать потенциальных клиентов на карте. |
| `campaigns:write` | Создавать контакты и черновики кампаний, обновлять настройки бренда, генерировать черновики с помощью ИИ и импортировать потенциальных клиентов с карты. |
| `campaigns:send` | Запуск черновика кампании. |

Используйте `campaigns:read` для чтения, `campaigns:write` для черновиков и изменений, `campaigns:send` для разрешённых действий отправки. Согласие OAuth по-прежнему необходимо.

<Note>
  Токены личного доступа используются для аутентификации в [API разработчика](/ru/agents/api), но не подходят для `/mcp`. Клиент MCP должен пройти вход через OAuth.
</Note>

## Доступные инструменты

| Задача | Инструменты | Область доступа |
| --- | --- | --- |
| Просмотр рабочего пространства | `get_current_user`, `list_contacts`, `list_campaigns`, `get_campaign`, `get_campaign_stats`, `get_brand_settings` | `campaigns:read` |
| Поиск компаний поблизости | `search_map_leads`, `retry_map_leads_enrichment` | `campaigns:read` |
| Создание и редактирование | `create_contact`, `create_campaign`, `update_brand_settings`, `generate_email_draft`, `import_map_leads` | `campaigns:write` |
| Запуск черновика кампании | `launch_campaign`, `send_test_email`, `activate_lifetime_campaign`, `trigger_lifetime_campaign` | `campaigns:send` |

`create_campaign` сохраняет **черновик кампании (`one-time`, `drip` или `lifetime`)**. Этот инструмент не может напрямую отправить или запланировать кампанию. С помощью `get_campaign` можно проверить тему, содержимое, ссылку, аудиторию и отправителя перед запуском.

Сервер также предоставляет ресурсы только для чтения в области доступа `campaigns:read`:

| Ресурс | Содержимое |
| --- | --- |
| `nudgen://api-catalog` | Названия и описания доступных инструментов. |
| `nudgen://team/brand` | Настройки бренда подключенного рабочего пространства. |
| `nudgen://campaigns/{id}/summary` | Статистика доставки одной кампании. Замените `{id}` идентификатором кампании. |

### Поиск и импорт потенциальных клиентов с карты

1. Попросите ассистента вызвать `search_map_leads`, указав местоположение и ключевые слова для поиска компаний, например город и `marketing agency`.
2. Дополнительные фильтры: `radiusKm` (1–100), `lat`, `lng` и `emailOnly`, чтобы оставить только компании с опубликованным email-адресом.
3. Если результат содержит `nextPageToken`, передайте его как `pageToken`, чтобы загрузить следующую страницу.
4. Попросите ассистента вызвать `import_map_leads` с теми же местоположением и ключевыми словами, а также объектами потенциальных клиентов, которые нужно сохранить. Один вызов принимает до 200 потенциальных клиентов.

При импорте контакты записываются в подключенное рабочее пространство. Потенциальные клиенты без email-адреса пропускаются. Если такой потенциальный клиент уже существует, его данные обновляются.

### Запуск черновика кампании

1. Проверьте название, тему, содержимое, фактического отправителя, оценку числа получателей и время через `get_campaign`.
2. Разрешите действие в чате. Ассистент напрямую вызывает `launch_campaign` с ID кампании и `sendNow: true` для немедленной отправки либо `scheduledAt` с будущим временем и часовым поясом. Не передавайте противоречивые параметры времени. Уже данное разрешение не требует повторного подтверждения.
3. Проверьте возвращённые статус, время отправки и ссылку на панель. Постановка в очередь или планирование не означают доставку. При неопределённом результате проверьте `get_campaign` и `get_campaign_stats` перед повтором.

Nudgen продолжает проверять права рабочего пространства, готовность отправителя, допустимых получателей, подписку, квоту, версию кампании и очередь. Создание и редактирование сохраняют только черновики; для доставки нужен обработчик кампаний.

## Управление доступом

Откройте **Настройки** → **Ключи API** → **Подключённые приложения MCP**, чтобы проверить или отозвать доступ. Отзыв отключает токены. Потеря членства в рабочем пространстве тоже блокирует доступ. При необходимости подключитесь заново через OAuth.

## Устранение неполадок

| Симптом | Что делать |
| --- | --- |
| Вход не начинается | Убедитесь, что клиент поддерживает удаленный MCP через Streamable HTTP с OAuth и использует `https://app.nudgen.net/mcp`. |
| Инструменту нужны дополнительные разрешения | Подключитесь заново и подтвердите нужную область доступа для этого рабочего пространства. |
| Поиск контактов просит сузить результаты | Поиск сопоставляет имена и email-адреса и проверяет не более 5 000 контактов после фильтрации по тегам и статусу. Сузьте фильтры. |
| При импорте с карты компания пропускается | Сохраняются только потенциальные клиенты с email-адресом. Повторите поиск с `emailOnly: true` или выберите записи, в которых уже есть email-адрес. |
| Старая ссылка или инструмент подтверждения | Обновите список инструментов и разрешите прямое действие в чате; старые ссылки не могут запустить кампанию. |
| Запуск заблокирован | Проверьте статус черновика кампании, готовность отправителя, подходящие контакты, квоту тарифного плана и [домен отправителя](/ru/settings/sending-domains). |

Для сценариев, использующих bearer-токены и прямые конечные точки REST, см. [API разработчика](/ru/agents/api).

### Радиус поиска и обогащение

API и MCP используют 5 км по умолчанию и принимают целое `radiusKm` от 1 до 100 без диалога подтверждения панели. Сохраняйте параметры при передаче `nextPageToken` как `pageToken`. Даже пустая страница может иметь следующую.

`enrichmentPending` означает незавершённое исследование сайта. Проверяйте доступные `businessSummary` и `businessSources`. Импортированный контекст помогает персонализировать вступления кампаний. Отсутствующий email может ещё находиться в процессе поиска.

При наличии `enrichmentRetryToken` вызовите `retry_map_leads_enrichment` с `token` и правом `campaigns:read`. Токен привязан к подключённому workspace, действует 15 минут и используется один раз. Перед импортом объедините результаты по `placeId`. `emailOnly` фильтрует текущий ответ; лиды могут появиться после повтора.

## Редактирование черновиков и охват функций

Используйте `update_campaign` для редактирования существующего черновика и `delete_campaign` для его удаления. Обоим инструментам требуется `campaigns:write`; они не отправляют и не планируют письма. Новым разделам продукта нужны отдельные разрешения OAuth. При запросе подключитесь заново и подтвердите эти разрешения.

Список инструментов показывает доступные инструменты и их аргументы. Переход в браузер сам по себе не выполняет действие: завершайте платежи, авторизацию провайдеров, отправку приглашений, смену рабочего пространства и настройку конфиденциальных реквизитов выплат в браузере. MCP остаётся привязанным к разрешённому рабочему пространству. Администрирование, учётные данные, вебхуки, обратные вызовы отслеживания и внутренний помощник исключены.

Проверяйте охват API через `get_api_capabilities`. После разрешения в чате напрямую вызывайте `send_test_email`, `activate_lifetime_campaign` или `trigger_lifetime_campaign`. Тесты отправляются только на почту аккаунта. Активация lifetime разрешает будущие автоматические отправки. Подтверждение в браузере и ID подтверждения не нужны. При неопределённом результате проверьте статус или историю выполнения перед повтором.
