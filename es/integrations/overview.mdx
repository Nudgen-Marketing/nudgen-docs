## Por qué esto es importante

La conexión con una aplicación puede importar tus contactos actuales en Nudgen para que elijas una audiencia para tus campañas. Las funciones disponibles varían según la aplicación y la configuración del workspace. Consulta los detalles de la aplicación antes de depender de una sincronización o un evento de cliente.

## Encontrar una aplicación

1. Abre **Configuración** → **Integración** en la aplicación de Nudgen.
2. Busca por el nombre de la aplicación o filtra por **CRM**, **Comercio electrónico**, **Ventas y atención al cliente** o **Marketing y redes sociales**.
3. Selecciona **Conectar** o **Ver detalles** en una aplicación. La página de detalles muestra su disponibilidad actual y los requisitos del proveedor.

La sección **Aplicaciones conectadas** muestra las conexiones existentes, su estado, la hora de la última sincronización cuando está disponible y un enlace **Gestionar**. La etiqueta **Integración nativa** identifica una conexión gestionada mediante el flujo nativo de Nudgen.

## Entender la disponibilidad

| Lo que ves | Qué significa |
| --- | --- |
| **Sincronización de contactos disponible** | La importación de contactos de esta conexión está habilitada para tu workspace. Puedes continuar con la configuración. |
| **Verificación pendiente** | Nudgen todavía está verificando la conexión de la aplicación o la sincronización de contactos. Abre sus detalles para ver el siguiente paso. |
| **Es necesario configurar la conexión** | Nudgen debe configurar la aplicación antes de que puedas conectarla. Contacta con el equipo de soporte de Nudgen. |
| **La sincronización de contactos aún no está implementada** | La importación de contactos de esta aplicación todavía no está lista. |
| **Sincronización no disponible** | El proveedor tiene una limitación documentada para la sincronización de contactos. |

Una aplicación puede permitir el **acceso mediante Composio** aunque la sincronización de contactos no esté disponible. En ese caso, su página de gestión lo indica expresamente. El directorio también puede mostrar un método de conexión, como **OAuth** o **Clave API**, cuando dicho método está configurado y la integración está disponible. Estas etiquetas describen la configuración de conexión seleccionada; no garantizan que todas las funciones del proveedor estén disponibles en Nudgen.

La compatibilidad con eventos de clientes se evalúa por separado de la sincronización de contactos. Consulta [Eventos de campañas de por vida](/es/integrations/lifetime-events).
