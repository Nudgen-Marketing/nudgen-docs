## Descripción general

Nudgen aloja un servidor MCP en `/mcp` del origen de tu aplicación. Admite MCP `2026-07-28` mediante Streamable HTTP y requiere OAuth 2.1. Inicia sesión en el navegador y aprueba los permisos solicitados. Cuando esté disponible, elige un espacio de trabajo o autoriza explícitamente todos los espacios actuales y futuros a los que pertenezcas. Cambiar de espacio en el panel no cambia el predeterminado de MCP.

## Trabaja con varios espacios

Las conexiones existentes siguen limitadas a su espacio original hasta que vuelvas a conectarlas y apruebes un acceso más amplio. Con acceso a todos los espacios, las nuevas membresías están disponibles automáticamente. Perder la membresía bloquea las siguientes acciones en ese espacio. Los roles, suscripciones y cuotas se aplican por separado en cada espacio.

Usa `list_workspaces` con `page` y `pageSize` para consultar identificadores, nombres, slugs, roles y el espacio predeterminado. Requiere `teams:read`. Añade `workspaceId` a una llamada para elegir otro espacio solo para esa acción. Si lo omites, se usa el predeterminado de la conexión. Al revisar y enviar una campaña, pasa el mismo identificador explícito.

Elige el espacio predeterminado durante el consentimiento OAuth. Cámbialo en **Configuración → Claves API → Aplicaciones MCP conectadas** o llama a `set_default_workspace` con `workspaceId` y el permiso `teams:write`. El cambio afecta a todos los chats que usan esa conexión. Una selección para una sola llamada no cambia el predeterminado. Si se elimina el espacio o pierdes acceso, indica otro identificador o actualiza el predeterminado. Nudgen nunca elige un sustituto sin avisar.

```jsonl
{"name":"list_workspaces","arguments":{"page":1,"pageSize":25}}
{"name":"list_campaigns","arguments":{"workspaceId":"workspace_b"}}
{"name":"set_default_workspace","arguments":{"workspaceId":"workspace_b"}}
```

Los URI existentes usan el espacio predeterminado. Estas plantillas seleccionan un espacio explícitamente:

```text
nudgen://workspaces/{workspaceId}/brand
nudgen://workspaces/{workspaceId}/campaigns/{id}/summary
```

## Por qué esto es importante

Tu asistente puede consultar contactos, buscar empresas y crear borradores de campañas. Autoriza el envío o la programación en el chat; el asistente ejecuta la acción directamente sin enlaces de aprobación en el navegador.

## Conectar tu cliente

El endpoint de producción es:

```text
https://app.nudgen.net/mcp
```

Añádelo como **servidor MCP HTTP remoto** en un cliente compatible con OAuth. El cliente descubre el servidor de autorización de Nudgen desde el endpoint y abre un flujo de inicio de sesión y consentimiento en el navegador. Selecciona el workspace al que quieres que acceda el cliente y aprueba únicamente los scopes que necesita.

Documentos de descubrimiento:

| Documento | URL |
| --- | --- |
| Metadatos del recurso protegido | `https://app.nudgen.net/.well-known/oauth-protected-resource/mcp` |
| Servidor de autorización | `https://app.nudgen.net/mcp-oauth` |
| Tarjeta del servidor | `https://app.nudgen.net/.well-known/mcp/server-card.json` |

El servidor de autorización usa el flujo de código de autorización con PKCE S256, vinculación de recursos y rotación de tokens de actualización. Admite documentos de metadatos de ID de cliente y el registro dinámico de clientes.

Para Codex CLI, usa:

```bash
codex mcp add nudgen --url "https://app.nudgen.net/mcp" --oauth-resource "https://app.nudgen.net/mcp"
codex mcp login nudgen --scopes campaigns:read,campaigns:write,campaigns:send,teams:read,teams:write
```

Si ya hay configurado un cliente llamado `nudgen`, actualiza esa entrada con la URL `/mcp`.

| Scope | Qué permite |
| --- | --- |
| `campaigns:read` | Consultar el workspace, los contactos, las campañas y la configuración de marca, así como buscar leads en el mapa. |
| `campaigns:write` | Crear contactos y borradores de campañas, actualizar la configuración de marca, generar borradores con IA e importar leads del mapa. |
| `campaigns:send` | Lanzar una campaña en borrador. |

Usa `campaigns:read` para consultar, `campaigns:write` para borradores y cambios, y `campaigns:send` para acciones de correo autorizadas. El consentimiento OAuth sigue siendo necesario.

<Note>
  Los tokens de acceso personal autentican la [API de desarrollador](/es/agents/api), pero no autentican `/mcp`. Un cliente MCP debe completar el inicio de sesión mediante OAuth.
</Note>

## Herramientas disponibles

| Tarea | Herramientas | Scope |
| --- | --- | --- |
| Consultar tu workspace | `get_current_user`, `list_contacts`, `list_campaigns`, `get_campaign`, `get_campaign_stats`, `get_brand_settings` | `campaigns:read` |
| Encontrar negocios cercanos | `search_map_leads`, `retry_map_leads_enrichment` | `campaigns:read` |
| Crear y editar | `create_contact`, `create_campaign`, `update_brand_settings`, `generate_email_draft`, `import_map_leads` | `campaigns:write` |
| Lanzar una campaña en borrador | `launch_campaign`, `send_test_email`, `activate_lifetime_campaign`, `trigger_lifetime_campaign` | `campaigns:send` |

`create_campaign` guarda una **campaña como borrador (`one-time`, `drip` o `lifetime`)**. No puede enviarla ni programarla directamente. `get_campaign` te permite comprobar el asunto, el contenido, el enlace, la audiencia y el remitente antes del lanzamiento.

El servidor también expone recursos de solo lectura mediante `campaigns:read`:

| Recurso | Contenido |
| --- | --- |
| `nudgen://api-catalog` | Nombres y descripciones de las herramientas alojadas. |
| `nudgen://team/brand` | Configuración de marca del workspace conectado. |
| `nudgen://campaigns/{id}/summary` | Estadísticas de entrega de una campaña. Sustituye `{id}` por el ID de la campaña. |

### Buscar e importar leads del mapa

1. Pide al asistente que llame a `search_map_leads` con una ubicación y palabras clave del negocio, como una ciudad y `marketing agency`.
2. Los filtros opcionales son `radiusKm` (1–100), `lat`, `lng` y `emailOnly` para conservar los negocios que publican un correo electrónico.
3. Cuando el resultado incluya `nextPageToken`, pásalo como `pageToken` para cargar otra página.
4. Pide al asistente que llame a `import_map_leads` con la misma ubicación y las mismas palabras clave, además de los objetos de leads que quieres guardar. Cada llamada admite hasta 200 leads.

La importación crea contactos en el workspace conectado. Se omiten los leads sin correo electrónico. Si un lead ya existe, se actualiza.

### Lanzar una campaña en borrador

1. Revisa nombre, asunto, contenido, remitente efectivo, estimación de destinatarios y horario con `get_campaign`.
2. Autoriza la acción en el chat. El asistente llama directamente a `launch_campaign` con el ID y `sendNow: true` para enviar ahora o `scheduledAt` con una fecha futura y zona horaria. No combines horarios contradictorios. Una autorización existente no requiere otra confirmación.
3. Revisa el estado, la hora programada y el enlace al dashboard. En cola o programado no significa entregado. Consulta `get_campaign` y `get_campaign_stats` antes de reintentar un resultado incierto.

Nudgen sigue comprobando permisos del workspace, remitente, destinatarios aptos, suscripción, cuota, versión de campaña y cola. Crear y editar solo guarda borradores; la entrega requiere el worker de campañas.

## Gestionar el acceso

Abre **Configuración → Claves API → Aplicaciones MCP conectadas** para revisar el acceso, cambiar el predeterminado o desconectar. Desconectar una conexión de varios espacios revoca sus tokens y códigos de autorización pendientes en todos los espacios sin desconectar conexiones REST independientes. OAuth REST y el asistente integrado conservan sus límites actuales.

## Solución de problemas

| Síntoma | Qué hacer |
| --- | --- |
| El inicio de sesión no comienza | Confirma que el cliente sea compatible con MCP remoto mediante Streamable HTTP y OAuth, y que use `https://app.nudgen.net/mcp`. |
| Una herramienta necesita más permisos | Vuelve a conectar el cliente y aprueba el scope necesario para ese workspace. |
| La búsqueda de contactos te pide acotar los resultados | La búsqueda compara nombres y direcciones de correo, y examina como máximo 5000 contactos después de aplicar los filtros de etiquetas y estado. Acota los filtros. |
| La importación de leads del mapa omite un negocio | Solo se guardan los leads con correo electrónico. Repite la búsqueda con `emailOnly` establecido en true o elige leads que ya incluyan un correo. |
| Enlace o herramienta de aprobación antigua | Actualiza la lista de herramientas y autoriza la acción directa en el chat; los enlaces antiguos no pueden lanzar campañas. |
| Un lanzamiento está bloqueado | Comprueba el estado de borrador de la campaña, la disponibilidad del remitente, los contactos aptos, la cuota del plan y el [dominio de envío](/es/settings/sending-domains). |

Para scripts que usen tokens bearer y endpoints REST directos, consulta la [API de desarrollador](/es/agents/api).

### Radio de búsqueda y enriquecimiento

API y MCP usan 5 km por defecto y aceptan un entero `radiusKm` de 1 a 100, sin diálogo de confirmación. Mantén los parámetros al pasar `nextPageToken` como `pageToken`. Una página vacía puede tener una página siguiente.

`enrichmentPending` indica investigación del sitio pendiente. Revisa `businessSummary` y `businessSources` cuando estén disponibles. El contexto importado puede apoyar introducciones personalizadas. Un correo ausente puede seguir pendiente de investigación.

Si recibes `enrichmentRetryToken`, llama a `retry_map_leads_enrichment` con `token` y `campaigns:read`. El token está vinculado al workspace conectado, caduca en 15 minutos y se usa una vez. Combina los resultados por `placeId` antes de importar. `emailOnly` filtra la respuesta actual; pueden aparecer leads después del reintento.

## Editar borradores y cobertura

Usa `update_campaign` para editar un borrador existente y `delete_campaign` para eliminarlo. Ambos requieren `campaigns:write`; ninguno envía ni programa correos. Las nuevas áreas del producto requieren permisos OAuth propios. Vuelve a conectarte y aprueba esos permisos cuando se soliciten.

La lista de herramientas muestra las herramientas disponibles y sus argumentos. Los enlaces al navegador no ejecutan acciones. Usa el navegador para pagos, autorización de proveedores, invitaciones, creación/eliminación/ingreso a espacios y datos confidenciales de cobro. Seleccionar un espacio o cambiar el predeterminado por MCP no cambia el espacio del panel. Se excluyen la administración, las credenciales, los webhooks, los callbacks de seguimiento y el asistente interno.

Usa `get_api_capabilities` para consultar la cobertura. Tras autorizar en el chat, llama directamente a `send_test_email`, `activate_lifetime_campaign` o `trigger_lifetime_campaign`. Las pruebas solo se envían al correo de la cuenta. Activar lifetime permite futuros envíos automáticos. No se requiere aprobación del navegador ni ID de aprobación. Ante un resultado incierto, revisa el estado o historial antes de reintentar.
