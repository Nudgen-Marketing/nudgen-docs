## 此页面可帮助您做什么

了解三种广告系列类型及其生命周期。这可以帮助您选择正确的营销活动类型并解释您的营销活动列表。

## 开始之前

- 在 Nudgen 中上传的联系人
- 品牌配置（预设音调或自定义提示）

## 营销活动类型

### 一次性营销活动

向您选定的受众发送一次的一封电子邮件。当您想要执行以下操作时，请使用此功能：

- 宣布一项功能或活动
- 发送一次性重新参与爆炸
- 在构建较长的序列之前测试一条消息

您选择受众，AI 生成内容，您预览并发送（或安排）。

### 滴水序列

电子邮件之间存在延迟的多步骤营销活动（例如第 1 天、第 3 天、第 7 天）。当您想要执行以下操作时，请使用此功能：

- 在几天内推动不活跃的用户
- 跟进非打开者或非点击者
- 构建 Duolingo 式的保留流程

每个步骤都有自己的目标、主题和 AI 生成的主体。仅在延迟后，联系人才会进入下一步。您可以设置**自动停止规则**（例如，当收件人点击或打开电子邮件时停止），以便参与的用户停止接收后续步骤。

### 终身营销活动

终身营销活动随时准备应对来自您系统的事件。每个经过身份验证的触发器最多创建一次执行，并向该触发器中的联系人发送一次推送。

使用终身营销活动进行订单确认、付款提醒、基于事件的引导或后端发起的其他交易和保留电子邮件。它的受众始终是**触发器** - 它不会立即发送到已保存的联系人细分。

有关仪表板工作流程和集成指南，请参阅[使用终身营销活动](/cn/campaigns/lifetime)。

**受众类型：** 创建营销活动时，您可以选择接收者：**所有联系人**、**按标签**（仅具有选定标签的联系人）或 **手动**（手动选择收件人）。该向导会在您启动之前显示覆盖面估计值。

## 活动状态

|状态 |含义 |
| ---------- | --------------------------------------------------------------------------- |
| **草稿** |未发送。您可以编辑目标、受众、内容和时间表。         |
| **预定** |发送时间已设定。电子邮件将在预定时间发出。        |
| **活动** / **发送** |正在发送电子邮件。进度显示在仪表板上。     |
| **已发送** |所有电子邮件均已发送。内容被锁定；您可以查看分析。  |
| **停止**|活动被手动停止。有些联系人可能已经收到电子邮件；未来的滴水步骤被取消。 |

<Note>
营销活动一旦发送，您就无法编辑其内容或重新发送。创建新的营销活动以发送不同的消息。
</Note>

### 生命周期

生命周期营销活动使用单独的生命周期：**草稿** → **活动** → **暂停** → **活动**，或 **活动/暂停** → **已存档**。您无法重新激活已存档的营销活动。

当您暂停或存档终身营销活动时，Nudgen 会取消仍待处理或排队的执行。已在处理的执行仍可发送。对活动活动的更改仅适用于未来的触发器，因为每次执行都会存储内容和发送配置的快照。
