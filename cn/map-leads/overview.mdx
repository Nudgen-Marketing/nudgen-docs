## 本页可以帮助你做什么

使用**地图获客**在目标区域内查找商家、查看可用的商家联系方式，并将选中的潜在客户添加到 Nudgen 联系人。之后，你可以使用标签整理这些联系人，并将其作为外联活动的受众。

## 为什么这很重要

手动建立本地潜在客户名单非常耗时。地图获客将基于地图的商家搜索与联系信息补充结合起来，让你能够在同一个流程中，从位置和商家类别出发，获得可直接使用的联系人分组。

地图获客可以帮助你：

- 查找城市、街区、邮政编码或地图上某个地点附近的商家。
- 按商家类型搜索，例如 `marketing agency`、`law firm` 或 `design studio`。
- 查看地址、评分、网站、电话号码、邮箱和社交媒体主页等可用信息。
- 在选择潜在客户前筛选结果。
- 将选中的结果导出为 CSV，或直接导入你的工作区。

<Note>
  地图获客目前处于测试阶段。随着功能持续开发，其可用性、搜索覆盖范围和结果质量可能会发生变化。
</Note>

## 开始前

- 登录 Nudgen，并选择要接收所导入联系人的工作区。
- 确定你想要定位的位置和商家类型。
- 根据[套餐限制](/en/billing/overview)，确认工作区还有足够的联系人容量。
- 遵守适用于你的业务和收件人的外联、隐私与同意规则。

## 地图获客的工作方式

地图获客会在你提供的位置周边搜索商家。如果商家拥有网站，Nudgen 可能会检查其公开页面，例如首页、联系页面和关于页面，以查找已公开的企业邮箱与社交媒体链接。

每条结果可能包含：

- 商家名称和地址
- 地图位置
- 商家类别
- 评分
- 网站和域名
- 电话号码
- 已公开的企业邮箱
- LinkedIn、Facebook、X/Twitter 或 Instagram 主页

并非所有商家都会公开上述全部信息。你仍然可以查看没有邮箱的结果，但不能选择这类结果进行导出，也不能将其导入 Nudgen 联系人。

<Warning>
  找到邮箱并不代表该地址仍然有效、有人查看或适合用于你的活动。在联系潜在客户前，请检查选中的结果，并遵守适用的反垃圾邮件和隐私法律。
</Warning>

## 第一步：打开地图获客

1. 打开 Nudgen 控制面板。
2. 在侧边栏中选择**地图获客**。
3. 导入任何内容前，确认当前启用的是正确的工作区。

## 第二步：选择位置

在**位置**字段中输入城市、街区、邮政编码、地址或其他支持的地点。出现建议时请选择其中一项，以便 Nudgen 使用正确的地图区域。

你还可以：

- 点击**使用我的位置**，并允许浏览器访问你的位置信息。
- 在搜索前点击地图，选择一个具体地点。
- 以 `latitude, longitude` 格式输入坐标。

即使你拒绝浏览器的位置权限，仍然可以手动输入位置或在地图上选择地点。

## 第三步：输入商家关键词

在**关键词**字段中描述你想查找的商家类型。请使用具体类别，而不是宽泛的销售用语。

合适的示例包括：

- `marketing agency`
- `software company`
- `accounting firm`
- `staffing agency`
- `real estate agency`

你也可以使用搜索字段下方的类别快捷选项。地图获客会在浏览器中保存最近的搜索，方便你稍后重复搜索或将其移除。

## 第四步：搜索并查看地图

点击**搜索**。搜索结果会显示为地图标记和潜在客户卡片。

- 点击地图标记，定位到对应的潜在客户卡片。
- 将鼠标悬停在潜在客户卡片上，突出显示对应的地图标记。
- 如果还有下一页结果，请点击**加载更多**。
- 点击网站或社交媒体图标，在新标签页中查看该商家。

搜索结果的排序会优先展示具有实用联系信息的商家。实际覆盖范围仍取决于所选区域以及各商家公开的信息。

## 第五步：筛选结果

使用潜在客户列表上方的筛选控件，缩小当前结果范围：

- **网站** — 显示拥有网站的商家。
- **邮箱** — 显示已找到邮箱的商家。
- **电话** — 显示拥有电话号码的商家。
- **评分** — 将最低评分设为 3、4 或 4.5。

邮箱和网站筛选条件默认启用。如果你想查看范围更广的商家，请将其关闭。

筛选条件仅应用于页面中已经加载的结果。如果列表过短，请清除一个或多个筛选条件、点击**加载更多**，或进行范围更广的搜索。

## 第六步：选择潜在客户

勾选每张潜在客户卡片上的复选框，以保留相应结果。你也可以使用列表上方的复选框，选择当前所有可见且符合筛选条件的潜在客户。

只有包含邮箱的潜在客户才能被选择并导入。导入前请检查：

- 商家是否符合你的目标受众。
- 位置是否相关。
- 网站是否属于正确的商家。
- 邮箱是否适合用于商业外联。
- 电话号码、评分和社交媒体主页是否符合你的潜在客户资格标准。

## 第七步：导出或导入

### 导出选中的潜在客户

点击**导出**，将选中的结果下载为 CSV 文件。导出内容包括：

- 名称
- 地址
- 邮箱
- 电话
- 网站
- 评分
- 类别
- 纬度和经度

导出不会将这些商家添加到你的 Nudgen 联系人。

### 导入选中的潜在客户

点击**导入**，将选中且包含邮箱的潜在客户添加到当前工作区。

导入过程中，Nudgen 会：

- 如果工作区中尚无该邮箱，则创建新联系人。
- 如果相同邮箱已经存在，则更新现有联系人。
- 跳过任何不包含邮箱的选中结果。
- 使用与其他联系人相同的保护措施，加密导入的联系人详细信息。
- 添加 `map-lead` 标签。
- 添加位置标签，例如 `geo:austin-tx`。
- 添加关键词标签，例如 `kw:marketing-agency`。
- 保存来源详情，包括地址、网站、评分、搜索位置、搜索关键词和可用的社交媒体链接。

确认消息会显示已创建或更新的联系人数量。导入的联系人会显示在**联系人**中，并遵循常规的联系人验证和脱敏规则。

## 第八步：在活动中使用导入的潜在客户

1. 打开**联系人**，查看导入的记录。
2. 按 `map-lead`、`geo:` 标签或 `kw:` 标签筛选。
3. 移除不合适的联系人。
4. 创建活动，并选择相关标签作为受众。
5. 查看覆盖人数预估，并在正式启动前发送测试邮件。

例如，搜索 Austin 的营销机构可能会生成以下标签：

- `map-lead`
- `geo:austin-tx`
- `kw:marketing-agency`

如果你希望活动定位更精准，请同时使用位置标签和关键词标签。

## 最佳实践

- 从具体的城市或街区以及一个明确的商家类别开始。
- 逐一检查商家，而不是导入所有结果。
- 在适合的情况下，优先选择基于职能的企业邮箱，例如 `hello@`、`info@` 或 `sales@`。
- 针对不同位置或商家类别分别搜索，确保标签持续有用。
- 根据找到的受众定制活动内容。
- 正式启动前发送测试邮件，并检查发件人设置。
- 保持抑制和退订处理功能启用。

## 问题排查

<AccordionGroup>
  <Accordion title="没有显示任何商家">
    检查位置和关键词字段是否都已填写。选择建议的位置、尝试范围更广的商家类别，或在地图上选择附近的地点。
  </Accordion>
  <Accordion title="搜索后列表为空">
    当前启用的筛选条件可能隐藏了结果。清除邮箱、网站、电话或评分筛选条件。如果还有下一页结果，也可以点击**加载更多**。
  </Accordion>
  <Accordion title="商家没有邮箱">
    该商家可能没有在 Nudgen 可以访问的页面上公开邮箱。你可以查看其网站和其他可用信息，但不能选择该结果进行导出，也不能将其导入联系人。
  </Accordion>
  <Accordion title="使用我的位置无法正常工作">
    在浏览器或操作系统中允许 Nudgen 应用访问位置。如果你不想共享位置，可以手动输入地点或在地图上点击一个位置。
  </Accordion>
  <Accordion title="导入创建的联系人少于我的选择数量">
    系统会跳过没有邮箱的结果。如果工作区中已经存在匹配的邮箱，系统会更新现有联系人，而不会将其计为新联系人。请查看导入摘要，了解创建、更新和跳过的总数。
  </Accordion>
  <Accordion title="相同联系人已经存在">
    Nudgen 会在当前工作区中按邮箱匹配联系人。再次导入该潜在客户会更新现有联系人，而不是创建重复记录。
  </Accordion>
</AccordionGroup>

## 通过 AI 助手使用地图获客

如果你将支持的 AI 助手连接到 Nudgen MCP 服务器，它就可以搜索地图获客，并将批准的结果导入已连接的工作区。有关权限、搜索选项和导入限制，请参阅 [MCP 服务器指南](/en/agents/mcp)。

## 搜索半径与信息补充

仪表板的新搜索从5 km开始，只返回所选圆圈内的企业。没有后续页面时，可依次确认扩展到10、25和50 km。加载更多保留位置、关键词和半径；点击地图不会重新启动正在进行的搜索。

`enrichmentPending`表示网站调查尚未完成。查看可用的 `businessSummary` 和 `businessSources`。导入的企业背景可帮助个性化营销活动的开场内容。没有邮箱可能是调查仍在等待完成。
