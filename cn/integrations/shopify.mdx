---
title: "连接 Shopify 联系人"
description: "授权 Shopify，并选择所有客户或特定细分"
---

## 为什么这很重要

即使你尚未创建细分，也可以通过 Shopify 的**所有联系人**选项导入客户。选择特定细分则可以缩小来源受众范围。无论选择哪种方式，Nudgen 在判断联系人能否接收邮件时，都会继续考虑 Shopify 中的电子邮件营销状态。

## 通过应用目录连接 Shopify

1. 打开**设置** → **集成**，找到 **Shopify**，然后查看为你的工作区显示的可用性。
2. 选择**连接**。Shopify 设置页面会说明一个商店专属的私有分发应用。在授权过程中，Shopify 管理员需要在 Shopify Dev Dashboard 中批准安装。
3. 仅授予请求的 `read_customers` 和 `read_orders` Admin API 权限范围。选择**连接**，通过 Composio 授权 Shopify。无需在 Nudgen 中粘贴 Admin API 令牌。
4. 完成授权后，选择**所有联系人**或一个或多个 Shopify 细分，然后预览、确认权限并开始同步。共享步骤和限制请参阅[连接指南](/cn/integrations/connect-and-sync)。

目录中的设置流程独立于任何现有的 Shopify 原生安装。如果 Nudgen 显示**之前的连接**通知，请按照提示断开该连接，再通过 Composio 进行连接。断开连接后，已导入的联系人仍会保留。

## 选择合适的 Shopify 受众

| 选项 | 导入内容 |
| --- | --- |
| **所有联系人** | 已连接 Shopify 商店中的所有客户，包括不属于已保存细分的客户。 |
| Shopify 细分 | 属于所选已保存细分的客户。 |

**所有联系人**为排他选项：选择它会替换已经选择的细分，而选择某个细分则会替换**所有联系人**。同步仍受 10,000 个不同来源联系人的限制和工作区容量限制。如果 Shopify 无法列出细分，但仍可读取客户，**所有联系人**可能仍然可用。

在满足 Nudgen 其他限制的前提下，Shopify 中标记为已订阅的客户可能符合接收邮件的条件。已退订、未订阅、待处理、无效和已脱敏的营销状态均会被视为阻止状态。如果客户没有可用的邮件许可状态，系统不会默认其已同意接收邮件。同步前，请检查预览并确认邮件发送权限。

## 故障排除

<AccordionGroup>
  <Accordion title="无法连接商店">
    确认 Shopify 管理员已经批准商店专属应用的安装及其请求的权限范围。返回设置页面并重试**连接**。如果页面显示**需要配置连接**，请联系 Nudgen 支持。
  </Accordion>
  <Accordion title="导入的客户比预期少">
    检查是否误选了某个细分，而不是**所有联系人**。查看同步记录中的已导入、已更新和已跳过数量。没有可导入邮箱地址的 Shopify 客户可能不会成为 Nudgen 联系人。
  </Accordion>
  <Accordion title="账户需要重新连接">
    打开**已连接的应用** → **管理** → **重新连接**，然后再次授权同一个 Shopify 商店。
  </Accordion>
</AccordionGroup>
