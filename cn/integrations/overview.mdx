## 为什么这很重要

应用连接可以将现有联系人导入 Nudgen，供你为活动选择受众。不同应用和工作区配置所提供的功能并不相同。在依赖同步或客户事件前，请先查看应用详情。

## 查找应用

1. 在 Nudgen 应用中打开**设置** → **集成**。
2. 按应用名称搜索，或使用 **CRM**、**电子商务**、**销售与客户支持**或**营销与社交媒体**筛选。
3. 在应用上选择**连接**或**查看详情**。详情页面会显示当前可用性和服务提供商的相关要求。

**已连接的应用**部分会显示现有连接、状态、可用时的上次同步时间，以及**管理**链接。标有**原生集成**的连接由 Nudgen 的原生流程管理。

## 了解可用性

| 页面显示 | 含义 |
| --- | --- |
| **联系人同步可用** | 已为你的工作区启用此连接的联系人导入功能。你可以继续设置。 |
| **等待验证** | Nudgen 仍在验证应用连接或联系人同步。打开应用详情以查看当前下一步操作。 |
| **需要配置连接** | Nudgen 需要先配置该应用，你才能进行连接。请联系 Nudgen 支持。 |
| **联系人同步尚未实现** | 此应用的联系人导入功能尚未就绪。 |
| **同步不可用** | 服务提供商对联系人同步存在已知限制。 |

即使联系人同步不可用，应用也可能允许 **Composio 应用访问**。在这种情况下，其管理页面会明确说明。目录还可能显示 **OAuth** 或 **API 密钥**等连接方式，前提是该方式已配置且集成可用。这些标记说明当前选择的连接配置，并不表示 Nudgen 支持服务提供商的所有功能。

客户事件支持与联系人同步分开评估。请参阅[终身活动事件](/cn/integrations/lifetime-events)。
